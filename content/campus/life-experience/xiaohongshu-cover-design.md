## 封面图设计

在小红书的信息流中，封面图决定了用户是否会停下拇指。从社区经验看，封面图质量直接影响笔记的点击率——好的封面可以让 CTR 明显提升。封面图不需要专业设计功底，掌握以下规范和模板，就能做出高点击率的封面。

***

## 尺寸与比例

### 推荐尺寸

| 比例          | 尺寸（像素）      | 适用场景     | 信息流显示    |
| ----------- | ----------- | -------- | -------- |
| **3:4**（推荐） | 1080 × 1440 | 绝大多数内容   | 占据最大屏幕面积 |
| 1:1         | 1080 × 1080 | 产品展示、九宫格 | 面积较小     |
| 4:3         | 1080 × 810  | 横版风景、截图类 | 面积最小     |
| 16:9        | 1920 × 1080 | 视频封面     | 会被裁切     |

**核心建议**：优先使用 **3:4 竖版（1080 × 1440）**。这个比例在小红书信息流中占据的屏幕面积最大，视觉冲击力最强。在双列信息流中，竖版图片的展示面积约为横版的 1.5 倍。

### 安全区域

设计封面时需要注意"安全区域"——避免关键信息被遮挡：

* **底部 150px**：会被标题文字和头像遮挡
* **左下角**：会显示点赞数
* **右下角**：视频会显示时长标记
* **建议**：核心文字和关键视觉元素放在画面的**中上部 2/3 区域**

***

## 文字排版四原则

### 原则一：字数精简

封面上的文字不是正文，而是"视觉标题"。用户在信息流中扫一眼就要能接收到信息。

* **核心文案控制在 8-15 字以内**
* 最多分 **2-3 行**
* 每行不超过 **7 个字**
* 如果需要副标题，字号缩小到主标题的 50-60%

### 原则二：字体选择

| 内容调性  | 推荐字体         | 示例场景    |
| ----- | ------------ | ------- |
| 专业/干货 | 思源黑体、阿里巴巴普惠体 | 教程、测评   |
| 温暖/生活 | 站酷快乐体、汉仪润圆   | 日常分享、美食 |
| 高级/时尚 | 思源宋体、方正清刻本悦宋 | 穿搭、家居   |
| 手写/亲和 | 演示悠然小楷、手写杂字体 | 个人故事、情感 |

**关键规则**：

* 一张封面最多使用 **2 种字体**（主标题 + 副标题各一种）
* 主标题字体要**粗体/加粗**，确保缩略图中也清晰可见
* 避免使用过于花哨的艺术字体，信息流缩小后会糊成一团

### 原则三：层级分明

文字信息要有清晰的视觉层级，让用户的视线自然地从最重要的信息看到次要信息。

**三级层级体系**：

1. **主标题**（最大字号）：核心卖点，一眼能看到的信息
2. **副标题**（中等字号）：补充说明，提供额外信息
3. **标签/角标**（最小字号）：品类标签、系列编号等

**字号参考**（1080 × 1440 画布）：

* 主标题：72-120px
* 副标题：36-54px
* 标签文字：24-36px

### 原则四：对比度足够

文字必须和背景有足够的对比度，否则缩小后会看不清。

**确保对比度的方法**：

* **深色文字 + 浅色背景**：最安全的搭配
* **白色文字 + 深色半透明蒙版**：适合图片背景
* **描边/阴影**：给文字加 2-3px 的描边或投影
* **色块衬底**：在文字后面放一个纯色色块

**自检方法**：把设计稿缩小到手机屏幕 50% 的大小，如果还能清晰阅读文字，对比度就够了。

## 配色策略

### 小红书热门配色方案

| 色系       | 色值参考              | 适用内容     | 情绪感受  |
| -------- | ----------------- | -------- | ----- |
| 奶油白 + 棕色 | #FFF8F0 + #8B6914 | 美妆、家居、咖啡 | 温暖、高级 |
| 莫兰迪色系    | #C4B6A6 + #A3B5C4 | 穿搭、生活方式  | 质感、克制 |
| 克莱因蓝 + 白 | #002FA7 + #FFFFFF | 干货、教程、职场 | 专业、信赖 |
| 薄荷绿 + 白  | #98FB98 + #FFFFFF | 健康、美食、清洁 | 清新、自然 |
| 浅粉 + 白   | #FFE4E1 + #FFFFFF | 美妆、恋爱、甜品 | 甜美、少女 |
| 黑 + 金    | #1A1A1A + #D4AF37 | 奢侈品、高端测评 | 高级、神秘 |

### 配色三原则

1. **全图不超过 3 种颜色**：1 个主色 + 1 个辅色 + 1 个点缀色
2. **60-30-10 法则**：主色占 60%，辅色占 30%，点缀色占 10%
3. **和内容调性匹配**：美妆用暖色、科技用冷色、美食用高饱和度

### 配色雷区

* 大面积使用高饱和度荧光色（刺眼、廉价感）
* 红配绿等互补色直接碰撞（除非你刻意追求复古风）
* 浅色文字配浅色背景（缩略图中完全看不到）

## 五种构图模板

### 模板一：居中大字型

**布局**：纯色/简单纹理背景 + 居中对齐的大号文字

**适用**：干货教程、知识分享、观点输出

**要点**：

* 背景要足够简洁，不要和文字抢注意力
* 文字占画面 40-60% 的面积
* 可以在文字上下加一条细线做装饰

### 模板二：左文右图型

**布局**：画面左侧 1/2 放文字，右侧 1/2 放产品图/人物图

**适用**：好物推荐、穿搭展示、测评

**要点**：

* 文字区域用纯色底
* 图片区域的主体要突出，去掉杂乱背景
* 文字区和图片区的分界线可以是直线、曲线或不规则形状

### 模板三：上文下图型

**布局**：上方 1/3 放标题文字（配色块底），下方 2/3 放大图

**适用**：旅行攻略、美食探店、家居展示

**要点**：

* 上方色块要和下方图片的主色调协调
* 图片质量要高，最好有一个清晰的视觉焦点
* 标题文字要精简（6-10 字）

### 模板四：九宫格/拼图型

**布局**：将 4-9 张图片拼在一起，搭配一个标题色块

**适用**：合集推荐、好物清单、before/after 对比

**要点**：

* 每张子图的色调要统一（可以统一加一个滤镜）
* 标题色块放在左上角或正中央
* 子图之间留 2-4px 的白色间距

### 模板五：人物 + 文字型

**布局**：人物占画面主体，文字叠加在空白区域或用色块衬底

**适用**：个人分享、穿搭 OOTD、妆容教程

**要点**：

* 人物的视线方向应该朝向画面内侧
* 文字避开人物面部
* 人物照片的光线要好（自然光最佳）
* 表情要有感染力（惊喜、微笑、夸张都行，避免面无表情）

## 封面设计自检清单

做完封面图后，对照以下清单检查：

1. **尺寸正确吗？** 3:4 竖版（1080 × 1440）
2. **缩小后文字还清晰吗？** 缩小到 50% 检查
3. **核心信息在安全区域内吗？** 避开底部和角落
4. **颜色不超过 3 种吗？** 主色 + 辅色 + 点缀
5. **字体不超过 2 种吗？** 主标题 + 副标题
6. **文字有层级吗？** 主标题 > 副标题 > 标签
7. **整体风格和账号调性一致吗？** 保持视觉统一性
8. **有吸引力吗？** 假设你是用户，在信息流中会停下来看吗？

封面设计的终极目标只有一个：**让用户的拇指停下来。**不需要多漂亮，但一定要醒目、清晰、有信息量。
