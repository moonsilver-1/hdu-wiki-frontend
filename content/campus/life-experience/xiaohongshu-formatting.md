## 排版与 Emoji 规范

排版决定了笔记的"可读性"。同样的内容，排版好的笔记完读率可以比排版差的高出 2-3 倍。小红书是手机端阅读，用户的注意力高度碎片化——排版的核心任务是**降低阅读阻力**。

***

## 段落结构黄金法则

### 1. 总分总结构

每篇笔记的宏观结构建议遵循"总分总"：

* **总（开头）**：用 2-3 行概括全文核心价值，告诉用户"看完能得到什么"
* **分（主体）**：分点展开，每个点聚焦一个信息
* **总（结尾）**：总结要点 + 互动引导

这个结构的好处是：即使用户只看了开头和结尾，也能获取到核心信息。

### 2. 三行原则

小红书是手机阅读。手机屏幕一屏大约能显示 8-10 行文字。如果一段话超过 3 行，视觉上会形成一个"文字墙"，用户的本能反应是跳过。

**具体操作**：

* 每个段落控制在 **2-3 行**（约 40-60 字）
* 超过 3 行的内容，寻找逻辑断点拆分成两段
* 段落之间用 **空行** 分隔
* 如果一个段落确实需要更长，用 Emoji 或加粗打断视觉连续性

**反面案例**：

> 今天给大家分享一个我用了很久的护肤方法其实很简单就是每天早晚各用一次维C精华然后搭配烟酰胺的面霜坚持用了三个月之后皮肤真的亮了很多而且痘印也淡了不少关键是不贵两个加起来才一百多块钱。

**正面案例**：

> 分享一个用了 3 个月的护肤搭配，皮肤真的亮了很多✨
>
> 方法很简单：早晚各一次维C精华 + 烟酰胺面霜。
>
> 坚持 3 个月，痘印淡了、肤色均匀了。关键是两个加起来才 100 多块💰

### 3. 视觉化呈现

文字之外，利用格式元素增强信息的可扫描性：

* **加粗**：标记每段的核心关键词（1 段最多加粗 1-2 处）
* **数字编号**：有序列的内容用 ①②③ 或 1⃣2⃣3⃣
* **分隔线**：不同板块之间用 `- - -` 或 Emoji 分隔线（如 `┈┈┈┈┈┈┈┈┈`）
* **缩进/引用**：重要的引用或公式可以单独成段，用引号包裹

## Emoji 的三大功能

Emoji 在小红书笔记中不是装饰，而是功能性元素。用好 Emoji 能显著提升笔记的可读性和视觉吸引力。

### 功能一：结构标记

用 Emoji 作为每个要点的"项目符号"，替代纯文字编号，视觉上更突出。

**常用结构标记 Emoji**：

| 场景    | 推荐 Emoji | 示例           |
| ----- | -------- | ------------ |
| 步骤/教程 | ✅ 📌 💡  | ✅ 第一步：清洁面部   |
| 产品推荐  | 🌟 ⭐ 💎  | 🌟 推荐一：XX 面霜 |
| 注意事项  | ⚠️ ❌ 🚫  | ⚠️ 注意：敏感肌慎用  |
| 优点    | ✔️ 👍 💯 | ✔️ 持妆力很好     |
| 缺点    | ❌ 👎 💔  | ❌ 质地偏厚重      |
| 总结    | 📝 📋 🔑 | 📝 总结：适合油皮   |

### 功能二：情绪表达

Emoji 能传递文字难以精确表达的情绪和语气，让文案更有"人味"。

| 情绪 | Emoji     | 使用场景   |
| -- | --------- | ------ |
| 惊喜 | 😱🤯✨     | 发现好东西时 |
| 推荐 | 💕🫶❤️‍🔥 | 真心推荐时  |
| 吐槽 | 😭💀🤡    | 自嘲或吐槽时 |
| 提醒 | 👀📢‼️    | 强调重点时  |
| 省钱 | 💰🤑💸    | 性价比相关时 |

### 功能三：视觉分隔

在长文中，Emoji 可以充当段落之间的视觉分隔符，打破文字的单调感。

**分隔线示例**：

```
🔸🔸🔸🔸🔸🔸🔸🔸
┈┈┈┈┈┈┈┈┈┈┈
✦ ✦ ✦
```

## Emoji 使用规范

### 用量控制

* **标题**：0-2 个 Emoji，放在末尾或关键词旁
* **正文**：每段 0-1 个 Emoji，全文控制在 **8-15 个**
* **关键规则**：Emoji 密度不超过总字数的 5%

### 避免的错误

**错误一：Emoji 堆砌**

> 💕✨🌈今天给大家推荐🤩一款超级好用的面霜😍💖真的太绝了🔥🔥🔥姐妹们快冲💪💪

问题：Emoji 多到喧宾夺主，干扰阅读。

**错误二：Emoji 与内容不匹配**

> 今天去医院看了一下皮肤问题 🎉

问题：情绪不对，容易引起误解。

**错误三：同一个 Emoji 连续使用**

> ⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐

问题：超过 5 个重复 Emoji 看起来像刷屏。

### 最佳实践

1. **一段一个功能性 Emoji**：每段开头用一个 Emoji 做标记就够了
2. **Emoji 与文字搭配**：Emoji 后面一定要有文字解释，不要让 Emoji 独立承载信息
3. **同一篇笔记风格统一**：要么用圆形 Emoji（🔵🟢🔴），要么用方形（🟦🟩🟥），不要混用
4. **适配内容调性**：专业测评用克制的 Emoji（📌✅），日常分享可以活泼一些（💕✨）

## 不同内容类型的排版要点

### 干货教程类

```
标题（含关键词）

开头钩子（2-3 行）

📌 要点一：XXX
具体说明（2-3 行）

📌 要点二：XXX
具体说明（2-3 行）

📌 要点三：XXX
具体说明（2-3 行）

💡 总结
一句话总结 + 引导收藏
```

**排版关键**：结构感 > 一切。用编号和 Emoji 让每个要点一目了然。

### 好物种草类

```
标题（产品名 + 核心卖点）

场景引入（痛点共鸣，2-3 行）

产品引出（自然过渡）

🌟 卖点一：XXX
体感描述

🌟 卖点二：XXX
体感描述

使用效果（带数据或 before/after）

💡 适合人群 + 购买建议
```

**排版关键**：图文搭配。每个卖点最好配一张细节图。

### 个人故事类

```
标题（悬念/结果前置）

故事开头（背景 + 冲突）

故事发展（2-3 个段落）

转折点

收获/感悟

对读者的建议
```

**排版关键**：不需要太多 Emoji 和格式，自然段落为主。故事类的排版要像"朋友发的长消息"，太格式化反而显得不真实。

### 清单合集类

```
标题（数字 + 品类）

一句话说明清单的价值

① XX名称 - 推荐理由（1 行）
② XX名称 - 推荐理由（1 行）
③ XX名称 - 推荐理由（1 行）
...

使用建议 + 引导收藏
```

**排版关键**：格式高度统一。每条的结构必须一致，让用户形成阅读节奏。

## 完整排版模板示例

以下是一篇干货教程类笔记的完整排版示例：

***

> 油皮护肤的 5 个误区，踩过 3 个以上说明你一直在走弯路😭
>
> 控油这件事，我走了整整 2 年弯路。现在终于搞明白了，把最重要的 5 个误区整理出来👇
>
> ┈┈┈┈┈┈┈┈┈┈┈┈
>
> ❌ **误区一：疯狂洗脸就能控油**
> 一天洗 3 次脸不会让你变干净，只会让皮肤觉得"太干了"从而分泌更多油脂。建议早晚各一次就够了。
>
> ❌ **误区二：油皮不需要保湿**
> 油 ≠ 水分够。很多油皮其实是"外油内干"，越不保湿越出油。选择清爽型的保湿凝胶就行。
>
> ❌ **误区三：控油产品越强越好**
> 酒精含量高的控油产品短期有效，长期会破坏皮肤屏障。选温和的水杨酸类控油产品。
>
> ❌ **误区四：不防晒因为怕闷痘**
> 紫外线会刺激皮脂腺分泌更多油脂。不防晒 → 更油 → 更容易长痘。选清爽型防晒就行。
>
> ❌ **误区五：频繁去角质**
> 一周去角质不要超过 1 次。过度去角质 → 屏障受损 → 出油加重 → 恶性循环。
>
> ┈┈┈┈┈┈┈┈┈┈┈┈
>
> ✅ **正确的油皮护肤顺序**
> 温和洁面 → 补水精华 → 清爽保湿 → 防晒
>
> 就这么简单，不需要叠加 7、8 层。少即是多。
>
> 觉得有用的话点个收藏📌 下次护肤的时候翻出来对照一下～

***

好的排版不是花哨，而是**让信息更容易被接收**。记住这个核心原则，排版就不会出错。
