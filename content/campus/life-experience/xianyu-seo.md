这一页讲的是卖服务（写代码、做设计、做 PPT、剪视频、技能辅导）怎么把一个商品做得能被搜到、被点开、被咨询，不是卖二手实物。

前置阅读：[曝光与流量机制](/campus/life-experience/xianyu-algorithm)——那页讲流量从哪来，这页讲怎么接住。

## 搜索是怎么匹配的

平台公开过的机制：倒排索引做文本匹配、正排索引做过滤排序；查询理解包含错词改写（「平果 → 苹果」）、同义词合并（「pingguo → 苹果」）、类目预测；检索分海选、粗排、精排三阶段。

对写标题的人，有用的是这三条：

1. 错别字和拼音会被归一化，所以指望写错别字避开竞争不太靠谱
2. 类目参与相关性计算，选错类目会真的影响召回
3. 多词组合查询是求交，长尾词只要在文本里出现就能被召回

至于详情正文参不参与搜索索引，卖家的说法分两派，谁也拿不出证据。安全的做法很简单：**核心词必须进标题，同义词和长尾词自然写进描述，但别指望描述能救标题。**

## 标题

上限 30 个汉字 / 60 字符。

### 服务类的骨架

实物的标题公式（「品牌词 + 产品词 + 修饰词 + 热搜词」）迁不到服务上——服务没有品牌词。从搜索机制反推，该做的是把买家真会敲进搜索框的词放前面：

```
[承接方式] + [品类 / 技术栈] + [交付物] + [交付承诺]
```

* **承接方式**：代做 / 定制 / 承接 / 接单 / 一对一
* **品类或技术栈**：Python 爬虫 / React 前端 / PPT 美化 / 剪映短视频 / Figma UI
* **交付物**：源码 / 可运行项目 / 成品 PPT / 成片
* **承诺**：当天出稿 / 免费改 3 次

几个可以直接改的例子：

```
代做Python爬虫数据采集 定制脚本 含源码注释 当天交付
承接PPT美化设计 商业路演汇报答辩 定制排版 3天出稿
视频剪辑代剪 口播Vlog短视频 调色字幕封面 24小时出片
一对一编程答疑辅导 Python C语言数据结构 讲思路不代做
```

> **两类词别往标题里放**：
> 
>   一是代写作业、代写论文、代做毕设这类——它们在《信息发布规范》里是明文禁售，不是灰色地带（见 [平台规则与合规经营](/campus/life-experience/xianyu-compliance)）。
> 
>   二是「七天无理由退货」「一手货源」「有售后」——这些是 2026-06-01 起经营性卖家认定的信号词，写上去等于主动举手。

### 堆词还有没有用

卖家里一派说闲鱼严打标题堆砌，一派说它根本不管堆砌、管的是重复铺货。从能查到的处罚记录看，后者更接近实际——处罚集中在重复铺货、滥发信息、直接复制他人标题，没见过因为「关键词密度」被罚的。

还有一个变化被很多人拿来说事：GSID 把商品理解从关键词升级到了多模态语义指纹，所以堆热词没用了。**这个推论方向上说得通，但没有任何卖家实测支撑**——做闲鱼的人里根本没人用过这个词，详见 [曝光与流量机制](/campus/life-experience/xianyu-algorithm)。

与其纠结要不要塞满 30 字，不如把 30 字用来讲明白：你做什么、交付什么、多久。

「前 10 个字最重要」这个说法有个很朴素的解释——移动端列表页会截断标题。这是点击率层面的常识，跟算法权重无关，但它是真的。有卖家的经验版本是「前 12 个字必须包含核心关键词」，说的是同一件事。

### 与其猜，不如抄排在前面的

做服务单的人里，方法最接近实验的是这一套：

> 多换几个闲鱼号，用不同关键词搜索，把搜索排名靠前的文案整合到一起，发出去看自然曝光，再用其他手机测试验证。

另一位的说法更简单：多看同行发的文案，搜关键词看自己能排到哪里，看排在前面的怎么写。

这不算严格的对照实验（没有对照组），但它至少是在看真实排序结果，比背一个「五元素标题公式」靠谱。市面上那些「核心词 + 属性词 + 场景词 + 情感词 + 促销词」的公式，在几个内容农场上措辞几乎一模一样，是同一批洗稿。公式本身不算错，但**它被包装成秘诀而不是常识**这件事本身就是信号。

### 服务类要带场景词

只写品类词会输给写场景词的。做 PPT 那位给的对照很直观：

```
✅ 毕业答辩PPT 美化代做 送演讲逐字稿
✅ 商业计划书BP PPT 创业路演 一稿过
✅ 工作总结PPT 述职报告 职场晋升神器
❌ PPT代做
```

场景词直接命中买家真正敲进搜索框的东西，顺手还完成了人群筛选。

### 敏感词是硬约束，优先级高于所有文案技巧

一位在闲鱼做了七八个月技术单的人留下过这条：

> 发闲置时要注意敏感词，比如代写、代开发、微信这些，尤其是新店铺。这些关键词对老号来说可能不算敏感词，但对新号绝对算，发一个轻则删除商品、重则扣分。

**同一个词在新号和老号上的待遇不一样**，这解释了为什么网上关于「能不能写代做」的说法互相打架。新号阶段一律避开，等号稳了再试。

## 详情正文

没有公开的字数上限，卖家的经验是 200 字左右讲清楚就够。

### 七段结构

1. **一句话说清「我能交付什么」**
2. **明确的不接范围**——这既是合规声明，也是无效咨询过滤器
3. **分档报价 + 加急规则**——服务的「一口价」往往只是起步价，不列档位会招来一堆砍价
4. **交付物清单**
5. **修改政策与周期**
6. **下单流程**
7. **案例指引**（「见图 2–图 6」）

第 2 条是新手最容易漏的，但它在纠纷里最值钱——没有「不包含什么」的详情，等于没有范围。

**把限制条件前置，是跨品类共识度最高的一条。** 做 AI 绘画栽过跟头的那位第一条建议就是「设改稿上限，超过 3 轮要么加钱要么止损」；做 PPT 那位写「下单前明确免费修改 3 次，超出每次加收 10 元，绝大部分客户不会故意刁难」；做修图的团队给的是「设一个你愿意接受的最低报价下限，低于这条线一律不回复」。

不过有一件事要如实说：**真正把「以下情况不接」写成详情页固定段落的，晒出来的人反而没有。** 能查到的执行位置几乎全在聊天环节——自动回复、报价下限、直接拒接。合理的解释是详情页的阅读率本身就低，有卖家专门写过「不看详情反复问的，基本都不会买」。

所以详情页写清边界是为了留下书面依据，真正拦人的那道闸在你的第一条回复里。两边都要做。

一个可以直接改的例子：

```
接单范围：Python 爬虫 / 数据清洗 / Excel 自动化 / 简单后端接口
不接：涉及登录绕过、验证码破解、批量注册等违规需求

报价（以实际需求为准）
· 基础版 单站点采集脚本，200 元起
· 进阶版 多站点 + 增量更新 + 定时任务，500 元起
· 加急 24 小时内交付，+30%

交付内容：可运行源码 + 依赖清单 + 使用说明 + 一次远程调试
修改政策：需求不变的前提下免费修改 3 次
交付周期：常规 2–3 天，简单需求当天

下单流程：先私聊说清需求和数据量 → 我报价并确认工期 → 站内拍下 → 交付验收
可先看历史交付案例（图 2–图 6）
```

### 导流检测比想象中严

这一段值得认真看，因为很多人是在这里栽的。

平台已经具备的能力：

* **文本侧用 NLP 模型识别整个联系方式语义场**——「V」「VX」「威信」这类变体同样会被认出来
* **图片侧有 OCR** 扫描图内文字，命中微信号格式会触发屏蔽
* **含二维码的图片有专门的降权逻辑**
* 用户举报会转人工，人工比机器严

规则里对应的是【引导站外交易】，原文把「二维码、超链接、联系账号」以及「变异文字、图片、语音、视频」都算进去，还特别点名「在头像、个人主页背景图片中添加引导到第三方平台交易的内容」。

扣分是一般 1 分 / 严重 20 分 / 特别严重 100 分。所以「发一次微信就永封」是夸张的，但有个细节要留意：**「刻意规避」本身就是判定「特别严重」的条件之一**。也就是说，用谐音、拆分、图片藏号码这些手段，被抓到时的定性比直接留号码更重。

市面上这类做法确实很多，本站不整理具体手法——不是回避，是因为它的期望值算不过来：省下的 0.6% 服务费，对不上一个 100 分的风险。合规的替代路径见 [接单全流程](/campus/life-experience/xianyu-order-flow)。

## 图

单个商品最多 9 张图。服务没有实物可拍，卖家的做法集中在四类：

| 类型                         | 适用               | 注意                       |
| -------------------------- | ---------------- | ------------------------ |
| **作品集拼图**                  | 最主流，首图放最能代表水准的一张 | 用客户作品要拿授权                |
| **文字海报**（服务清单 / 价目表 / 流程图） | 信息密度高            | 纯文字图容易被 OCR 扫到敏感词，观感也像广告 |
| **对比图**（改前 / 改后）           | PPT 美化、视频剪辑最吃这个  | —                        |
| **工作场景 / 屏幕录制截帧**          | 增强真实感            | —                        |

**服务和实物在拍什么上是反的：实物拍瑕疵，服务拍差值。** 左边是客户给的原始文字或者丑排版，右边是成品——这是服务类主图少数几个明确有效的做法。

要不要做海报式的「专业感」主图，两条路都有人走。做毕设中介那位明确否掉了：最开始也考虑参考同行做海报，但同质化太严重，最后主图用了自己的一张生活照加大量自定义标签，力气全花在打磨文案上。这两条路都没有对照实验，别把任何一条当定论。

几条要点：

* **盗图是可以被举报的**。闲鱼有知识产权投诉和盗图举报两条路径，证明原创最有效的方式是提供**相机原图的 EXIF 参数截图**——「我发得早」不构成有效证据。所以用网上找的作品图当案例，风险不在平台查，在同行举报。
* 图片上限是 9 张（更早的版本是 10 张，需要 App 升级到 v7.12.0 以上才是 9 张的新逻辑）。主图比例卖家常推荐 1:1 或 3:4。
* **视频时长没有可靠的当前数字**：有人说 15 秒，有人说 30 秒，也有人说自己传过 5 分钟以上的。一个可能的解释是 App 内拍摄和从相册导入两条路径的上限不一样。实操里大家普遍按 15 到 30 秒做，以你发布页实际允许的为准。
* 网上「视频提升转化率 30%」「主图决定 70% 点击率」这类数字没人能验证。方向是对的——首图确实是决定点不点开的那一下——但别拿数值当依据。

## 价格

### 真实的市场锚点

2026 年上半年闲鱼 AI 服务的官方数据：

* AI 服务订单 981.6 万单，同比 +157%；近 500 万人购买
* 卖家人均月成交额 897 元；超过 41% 的从业者副业收入占月收入 30% 以上
* 结构：AI 技能 45.1%（绘画设计、漫剧、短视频、配音、编程）、AI 教程课程 8.1%、模板与工作流 6.6%
* 增速最快：AI 编程与建站 +1732%、AI 漫剧 +1425%、AI PPT 办公类 +264%
* 实际价位：电商文案代写 50 元/份；AI 漫剧教程 9.9 元，半年卖 1.7 万份、流水 16 万；商业设计课程 99–1999 元分档

**人均月成交 897 元**这个数字值得记住——它是这门生意的中位数现实，不是那些「月入过万」的宣传口径。同时它也说明：标品化、可复用的东西（教程、模板）比一对一定制更容易上量。

### 低价引流的边界在哪

低价引流是会被处罚的：以远低于市场价上架吸引咨询，容易被同行举报后直接下架；0.01 元、0.1 元的超低价虚拟商品是风控高危对象，有卖家因此永久封号并被扣款。

卖家里流行「9.9 元引流款 + 29.9 元组合装 + 59.9 元年度会员」的三档定价，实践中 9.9 元这一档很少出事，0.1 元这一档出事的多。中间的线在哪没有公开标准——但从判罚逻辑看，被盯上的通常不是绝对价格低，而是**低到明显不像在做真实交易**。

对服务类还有一个更实际的理由：低价筛来的是最难伺候的客户。这笔账比风险那笔更容易算清。

### 手续费要算进报价

| 对象    | 费率                          | 生效         |
| ----- | --------------------------- | ---------- |
| 普通卖家  | 0.6%，单笔 60 元封顶              | —          |
| 鱼小铺卖家 | 1.6%，无封顶，运费红包计入基数，**退款不退费** | 2026-04-18 |
| 手机品类  | 自然年内成交超 6 件触发 1%，合计最多 1.6%  | 2025-04-01 |

虚拟商品要开通「描述不符全额退」服务需缴 500 元保证金。

接一单 3000 元的项目，鱼小铺要交 48 元，而且退款了这笔也不退。

## 类目

闲鱼有专门的服务发布入口，不用硬塞进实物类目：

* **2024-07** 上线「闲鱼简历」与「神奇副业」，首批八大类、数百个类目，覆盖跑腿代办、兴趣手艺、专业技能、热门副业（含软件开发）
* **发布路径**：底部「+」发布 → 发布页**底部**的「搞副业」入口 → 编辑闲鱼简历（支持图文和视频）→ 发布。发出来的东西汇聚在「简历集市」，首页另有「神奇副业」入口
* **「八大类」是 2024-07 首批上线时的数字，现在不是了。** 2025-07 的官方口径已经是 24 个大类，涵盖平面设计、IT 开发、情感聊愈、工业设计、宠物服务、家政服务、婚庆服务等
* **2025-06** 上线「闲鱼夜市」内容频道，主打技能服务与咨询
* 发布时逐级选一级和二级类目；已发布的商品可以编辑改类目，但不能跨一级大类

要资质的服务类目（未备案发布本身就是违规，严重每次扣 20 分）：法律咨询 / 代理 / 法律文书代拟、专利 / 知识产权 / 商标 / 版权代理、工商注册登记、会计服务、租房。

兼职信息类要求发布主体必须是企业或获得企业授权，个人发兼职招募是违规的。

至于「代做 PPT」该发在「技能服务」还是「虚拟商品」，两边都有人做。区别在于流量池不同：技能服务走简历集市和副业频道，虚拟商品走搜索加自动发货体系（自动发货需要鱼小铺）。**没有标准答案，可以两边各发一个测。**

## 关键词矩阵：2026 年已经变危险了

卖家的经典做法是把同一个服务按「价格 × 主图 × 标题 × 卖点」排列组合，一个单品拆出 10 多个链接，把 50 个展位用满。

这个打法本身是有效的——多占位就是多召回，逻辑上没问题。**但 2026-06-01 之后它的代价变了。**

经营性卖家认定信号里有两条正好命中它：

* 一年内发布物品超过 30 件，且品类少于 3 类
* 同款商品反复售出超过 5 次

被认定后要办营业执照、履行七天无理由退货义务，发布数量和品类还可能受限。也就是说，这个打法现在是拿「短期多占位」换「提前触发身份认定」。

另外规则本身禁止「同一店铺内发布 2 个及以上完全相同的商品链接」——**拆链接要真的拆出差异**，不能只改个价格。

多号矩阵风险更高：它同时踩关联管控和重复铺货两条线。规则里写明平台可对同一实际控制人名下的其他账号一并处置——一个号出事，全套跟着走。

## 转化侧

### 三套信用体系

* **闲气值** — 扣分制安全分，`100 − 近 90 天扣分`，挂钩限权，鱼小铺申请要求高于 80 分
* **鱼力值** — 2023-05 上线的信用评级体系，计算维度没公开
* **芝麻信用** — 支付宝的分，闲鱼引用展示

「卖家信用等级」「店铺星级」「实力商家」这些词在后台找不到对应的东西，按它们去优化会白费劲。

### 议价

服务类的砍价比实物频繁得多，因为买家没有参照价。几条实用的：

* **不硬顶砍价，用价值或工期换价格**——「这个价我可以做基础版，不含增量更新」比「不刀」有效
* **给条件性优惠**——关注店铺、立刻拍下再减
* **回复要给明确答案**，模棱两可的回复直接流失
* **详情页列清档位**，能挡掉一半无效砍价

回复速度单独有一页：[回复速度与响应率](/campus/life-experience/xianyu-response-speed)。
