**图谱视图（Graph View）** 把你的所有笔记及其链接关系渲染为一个交互式的力导向图。

## 打开图谱

* **全局图谱**：`Cmd/Ctrl + Shift + G` 或命令面板搜索 "Graph view"
* **局部图谱**：右键某条笔记 → "Open local graph"

## 全局图谱

显示 Vault 中**所有笔记**和**所有链接**。

* **节点** = 笔记
* **连线** = 双向链接
* 节点大小 ∝ 链接数量（被链接越多，节点越大）

### 筛选设置

| 选项      | 说明                          |
| ------- | --------------------------- |
| Filters | 按搜索语法筛选显示的笔记（如 `tag:#永久笔记`） |
| Groups  | 按条件给节点着色（如 `tag:#认知科学` 染蓝色） |
| Display | 节点大小、连线粗细、是否显示标签等           |
| Forces  | 物理引擎参数（排斥力、中心力、连接力）         |

### 颜色分组

在 Groups 中添加规则：

* `tag:#永久笔记` → 🔵 蓝色
* `tag:#文献笔记` → 🟢 绿色
* `tag:#项目` → 🔴 红色
* `path:Templates` → ⚪ 灰色

这样图谱视图可以直观看出笔记类型的分布。

## 局部图谱

只显示当前笔记周围的链接网络，设置「Depth」控制显示深度：

* **Depth 1** — 直接链接的笔记
* **Depth 2** — 链接的链接
* **Depth 3** — 三层关系

局部图谱适合探索某条笔记的"邻域"。

## 图谱的使用场景

### 1. 发现孤岛

没有任何链接的独立节点 = 孤立笔记。考虑：

* 给它添加链接到相关笔记
* 或者它不够有价值，可以归档

### 2. 识别枢纽

大节点 = 被大量链接的笔记 = 核心概念。这些笔记值得定期回顾和完善。

### 3. 发现聚类

紧密连接的一组节点 = 自然形成的主题。考虑为这个聚类创建一个 [MOC](/tech/tool-use/obsidian-moc)。

### 4. 跨领域桥梁

连接两个不同聚类的笔记 = 跨领域的洞察。这些笔记往往是最有价值的。

### 5. 成就感

看到自己的知识网络越来越大、越来越密集，这种视觉反馈本身就是坚持记笔记的动力。

## 增强插件

* **3D Graph** — 把二维图谱变成三维，更直观
* **Graph Analysis** — 分析图谱中的中心性、社区检测等
* **Juggl** — 支持更多图谱交互方式

> 截至 2026-09-14，3D Graph 的仓库 2023 年后、Juggl 的仓库 2025-02 后没有新提交，安装前先确认兼容性。

## 注意事项

* 图谱视图在笔记很多时（>5000）可能比较卡
* 不要为了让图谱好看而乱加链接
* 图谱是**结果**不是**目标**——先关注写好笔记和链接，图谱自然会好看
