**双向链接（Backlinks）** 是 Obsidian 区别于普通笔记软件的核心功能。当你在笔记 A 中链接到笔记 B 时，笔记 B 会自动显示"谁链接了我"。

## 基础用法

### 创建链接

输入 `[[` 触发搜索，选择目标笔记：

```markdown
这个概念和 [[费曼学习法]] 有关。
```

### 创建不存在的笔记

链接一个还不存在的笔记，Obsidian 会显示为灰色链接。点击后自动创建：

```markdown
我想研究 [[量子计算在密码学中的影响]]
```

### 链接到标题

```markdown
参见 [[费曼学习法#第三步]]
```

### 链接到段落

```markdown
参见 [[费曼学习法#^paragraph-id]]
```

### 显示别名

```markdown
他用了 [[费曼学习法|费曼的方法]] 来解释量子力学。
```

渲染后显示「费曼的方法」，但链接指向「费曼学习法」。

## 嵌入（Embed）

用 `![[]]` 嵌入另一条笔记的内容：

```markdown
![[费曼学习法]]
```

也可以嵌入特定部分：

```markdown
![[费曼学习法#第三步]]
```

嵌入图片：

```markdown
![[diagram.png]]
```

## 反向链接面板

每条笔记的右侧可以打开「反向链接」面板，显示：

### 链接提及（Linked mentions）

其他笔记中使用 `[[这条笔记]]` 的地方。

### 未链接提及（Unlinked mentions）

其他笔记中提到了这条笔记的标题文字，但没有用 `[[]]` 链接的地方。你可以一键将其转为正式链接。

## 双向链接的价值

### 发现意外连接

你在不同时间写的笔记，可能有你没意识到的联系。通过反向链接面板，你会发现：

> "原来我三个月前写的那条笔记和这个新想法是相关的！"

### 知识涌现

当笔记之间形成足够多的链接后，知识网络会开始「涌现」——产生你单独看任何一条笔记都看不到的洞察。

### 避免重复

写新笔记时，搜索一下关键词。如果已有相关笔记，链接到它而不是重复写一遍。

## 最佳实践

1. **多链接少分类** — 与其纠结放哪个文件夹，不如多加几个链接
2. **链接时写原因** — `参见 [[X]]（因为它也讨论了决策疲劳）`
3. **关注未链接提及** — 定期检查，把有价值的转为正式链接
4. **不要为了链接而链接** — 每个链接都应该有理由
5. **跨领域链接** — 最有价值的链接往往连接不同领域的知识
