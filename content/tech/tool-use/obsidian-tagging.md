标签是 Obsidian 中除双向链接外的第二种组织方式。用好标签能大幅提升检索效率。

## 标签 vs 链接 vs 文件夹

| 维度   | 标签         | 链接       | 文件夹        |
| ---- | ---------- | -------- | ---------- |
| 关系类型 | 分类归属       | 概念关联     | 物理位置       |
| 一对多  | 一个笔记多个标签   | 一个笔记多个链接 | 一个笔记一个文件夹  |
| 搜索   | `tag:#xxx` | 反向链接     | `path:xxx` |
| 适合   | 分类筛选       | 知识连接     | 项目隔离       |

**最佳实践：标签管分类，链接管关系，文件夹管项目。**

## 标签层级

Obsidian 支持嵌套标签：

```markdown
#笔记类型/永久笔记
#笔记类型/文献笔记
#笔记类型/闪念

#主题/认知科学
#主题/编程/Python
#主题/编程/TypeScript

#状态/draft
#状态/done
#状态/review
```

### 推荐的标签体系

```
#type/         — 笔记类型
  permanent    — 永久笔记
  literature   — 文献笔记
  fleeting     — 闪念笔记
  project      — 项目笔记

#topic/        — 主题领域
  cs           — 计算机科学
  psychology   — 心理学
  productivity — 生产力

#status/       — 状态
  draft        — 草稿
  done         — 完成
  review       — 待回顾
```

## 标签数量控制

* 每条笔记 **2-4 个标签**足够
* 全局标签总数控制在 **50 个以内**
* 超过 50 个说明需要合并或简化

## 标签管理

### Tag Wrangler 插件

安装 Tag Wrangler 可以：

* 批量重命名标签
* 合并相似标签
* 在标签面板右键管理

### 定期清理

每月检查一次：

* 只用过 1 次的标签 → 考虑删除
* 意思相同的标签 → 合并
* 太宽泛的标签 → 细分或删除

## 常见误区

1. ❌ **标签代替链接** — 标签不能表达关系，只能分类
2. ❌ **标签过多** — 100 个标签 = 没有标签
3. ❌ **每个笔记都加全部相关标签** — 只加最核心的 2-3 个
4. ❌ **用标签做层级目录** — 那是文件夹的工作
