## 疑问与困惑

### 问题 1：P1S 自动调平、自动校准很多，是否就不需要理解切片？

- [ ] 已能在每次发送任务前独立检查材料、板材、预览路径和首层风险。

**问题分析**

P1S 自动化的是部分重复动作，例如设备自检、调平和执行切片后的路径；它无法判断模型用途、材料是否干燥、支撑是否会碰撞、模型是否该平放，或陌生耗材是否适合当前预设。

**详细解答**

把 P1S 理解为“自动执行能力很强的制造设备”，而不是自动替用户做工程判断的黑箱。每次打印至少由用户确认四件事：模型方向是否合理、耗材和板材是否匹配、切片预览是否存在异常路径、首层是否正常。理解这些检查点，比背大量参数更能减少失败。

**常见误区**

- 看到 MakerWorld 带有 3MF 文件就不检查它的喷嘴、材料或多色映射。
- 把首层失败完全归因于机器，忽略板面油污、受潮和材料预设。

**可执行验证方法**

选择一个 20–40 分钟的小模型，在发送前能说清楚：它用什么材料、什么板材、是否有支撑 / Brim、为什么这样摆放，以及预览中外墙和填充分别在哪里。

### 问题 2：P1SC、P1S Combo、AMS 和普通单机 P1S 的关系是什么？

- [ ] 已确认自己的设备是否含 AMS，并能识别耗材从 AMS 与外置料架进入时的不同路径。

**问题分析**

“P1SC”不是当前官方文档中的独立机型名称，日常通常用于表示 P1S Combo。Combo 的核心差异是额外配有 AMS；打印机、热端、切片机型仍按 P1S 选择。

**详细解答**

在 Bambu Studio 中选择 P1S 及实际喷嘴尺寸；有 AMS 时再设置槽位材料与颜色映射。AMS 用于自动换色 / 换料和相对密封的存放，不是所有材料的干燥设备，也不保证第三方线轴都能顺畅使用。柔软、易碎、潮湿或线轴尺寸不兼容的耗材，应按官方兼容说明改用外置料架或先处理线轴。

**常见误区**

- 将 AMS 内的耗材标签设成 PLA，却在切片中选择 PETG 或 ABS。
- 把 AMS 的干燥剂当作“湿料修复器”，不先干燥就直接打印。

**可执行验证方法**

在设备页逐槽核对实际耗材与软件显示的材料、颜色；打印单色小件时也确保选择的槽位和切片耗材一致。

### 问题 3：封闭式 P1S 是否可以在任何室内放心打印 ABS、ASA 等材料？

- [ ] 已为高温 / 有气味材料确认实际通风或对外排风方案。

**问题分析**

封闭机箱主要帮助维持热环境、降低翘曲；过滤系统也不能被视为对所有挥发物的零排放方案。材料的 SDS 与具体场地通风条件同样重要。

**详细解答**

PLA、PETG 等常见材料仍应在基本通风环境下使用。ABS、ASA 及其他可能产生明显气味 / 挥发物的材料，优先在通风良好的独立区域打印，并尽可能采用对外排风；打印时不要堵塞设备风道或为了升温擅自改造散热路径。有关温度、风扇、门盖和干燥的取舍，以该材料厂商 TDS 为准。

**常见误区**

- 因为闻不到气味，就认为没有暴露风险。
- 为了提高腔温遮挡排风口、风扇或主板散热。

**可执行验证方法**

在首次长时间高温材料打印前，写下材料、通风方式、预计时长和看护安排；若无法建立合适通风条件，先不要开始该类长时间任务。

## 正文

### 一、开始前：设备边界、公共设备规则与首次打印目标

本文将“P1SC”按 **P1S Combo（P1S + AMS）** 理解；若设备没有 AMS，切片时仍选择 P1S，只是把“AMS 槽位”替换为“外置料架”。P1S 是封闭式 CoreXY FDM 打印机，官方标注的构建体积为 256 × 256 × 256 mm；它能胜任很多常用材料，但能力边界仍由实际喷嘴、板材、耗材状态、环境和维护状态共同决定。

在社团或公共设备场景中，建议把操作权限分成两层：

| 事项 | 使用者可以完成 | 应暂停并交接给设备负责人 |
| --- | --- | --- |
| 常规准备 | 装卸兼容耗材、清洁板面、选择预设、切片预览、首层观察、冷却取件 | 不确定耗材、板材或喷嘴配置时 |
| 一般异常 | 取消明显失败的任务、拍照、记录报错和切片信息、检查可见的断丝 / 板面油污 | 加热报错、持续撞击、工具头积料、异常异响、风扇不转、线缆异常 |
| 维护与拆装 | 清理打印板、废料槽和外部碎屑；执行已获授权的例行维护 | 更换热端、拆挤出机、调皮带、处理电气或不熟悉的机械问题 |

首次打印的目标不是“挑战复杂模型”，而是完成一次可复现的闭环：用状态良好的 PLA、默认 0.4 mm 喷嘴、干净的对应打印板，打印一个 20–40 分钟的简单模型；保存 3MF 项目，并能解释材料、摆放、支撑 / Brim、首层和结果。复杂多色、ABS / ASA、柔性料与大模型，都应建立在这个基线之上。

### 二、基本概念扫盲：FDM 为什么会成功，也为什么会失败

FDM（熔融沉积成型，也常称 FFF）并不是“把模型按一下打印出来”。它的工作链是：将热塑性线材送入热端熔化，喷嘴按切片路径逐层挤出，层与层在合适温度和压力下结合，最后得到实体零件。

```text
用途与尺寸
  → 选材料与建模
  → 导出模型（STL / 3MF / STEP 等）
  → 切片：确定方向、支撑、层高、壁数、填充、温度、速度
  → 预览打印路径
  → P1S 执行：调平、加热、出料、逐层成型
  → 冷却取件、检查、记录与迭代
```

| 概念 | 对新手最重要的理解 | 直接影响 |
| --- | --- | --- |
| 层高 | 单层厚度；小层高更细腻，但耗时更长 | 外观、曲面细节、时间 |
| 外墙与壁数 | 外壳比填充更直接决定很多零件的强度 | 强度、螺丝孔、耐冲击 |
| 填充 | 内部支撑结构，不等于“越高越结实” | 重量、时间、顶部支撑 |
| 支撑 | 临时结构，用来承接无法悬空打印的区域 | 表面痕迹、拆除难度、失败风险 |
| Brim（边缘裙边） | 扩大首层接触面积，抑制翘边 | 高收缩材料和小接触面模型 |
| 耗材预设 | 定义该卷料的温度、冷却、流量等材料行为 | 附着、层间结合、拉丝、表面 |
| 工艺预设 | 定义层高、墙、填充、速度、支撑等模型工艺 | 强度、外观、时间 |

> [!warning] 不要把材料标称性能直接当成零件性能
> 同一卷料在不同层高、方向、风扇、干燥状态和填充方式下，实际强度可能差异很大。承力、耐热、长期户外或安全相关零件必须针对真实受力和环境打印试样验证。

#### 2.1 模型文件、项目文件与切片任务不是一回事

| 文件 / 概念 | 它通常保存什么 | 新手的正确用法 |
| --- | --- | --- |
| STL / OBJ | 网格形状，通常不保存材料、摆放和打印参数 | 导入后自己确认单位、朝向和工艺 |
| STEP 等 CAD 文件 | 可编辑的工程实体与尺寸关系 | 适合修改设计；通常要导出网格或由支持的软件导入后再切片 |
| 3MF 项目 | 可包含模型、摆放、颜色、材料与切片上下文 | 适合保存自己的成功方案；下载他人项目后仍须核对设备与耗材 |
| 切片任务 | 已被转换为设备可执行的运动、温度和换料指令 | 必须与实际打印机、喷嘴、材料和板材一致；不要把别的机器生成的任务直接拿来执行 |

“模型能打开”不等于“模型能打印”。切片器会把几何形状变成逐层路径；如果模型单位错了、壁厚小于可挤出的线宽、模型悬在空中或方向不合适，问题通常会在切片预览中暴露，而不是等打印失败后再解决。

#### 2.2 四个会反复出现的制造取舍

1. **层高与时间**：层高更小会让阶梯纹更细，但打印时间上升；它不是强度和精度的万能开关。一般先用 0.20 mm 的标准预设建立基线。
2. **壁数、填充与强度**：多数日常结构件，合理的方向、足够的外墙和圆角，往往比盲目把填充拉满更有效。填充还负责支撑顶部表面；过低会让顶面塌陷，过高则增加时间、材料和内应力。
3. **方向、支撑与外观**：大平面朝下通常最稳，但会把首层纹理留在该面；朝上或竖放可能更利于受力，却需要支撑并留下支撑痕。没有“永远正确”的朝向，只有对用途更合适的取舍。
4. **温度、速度与材料状态**：温度太低、速度过快或材料受潮，都可能造成欠挤、层间弱、粗糙与拉丝；不要只凭一种现象立即认定唯一原因。

#### 2.3 先用材料特性指导操作

| 材料 | 适合练习的用途 | 新手需要重点防范 | P1S 上的起点 |
| --- | --- | --- | --- |
| PLA | 外观件、尺寸样件、低温环境原型 | 高温环境软化；封闭腔体过热时的供料问题 | 干燥 PLA + 官方预设 + 简单模型 |
| PETG | 耐冲击、轻度耐热的功能件 | 拉丝、板面粘得过牢、受潮 | 注意板材要求和干燥，别直接照搬 PLA 支撑策略 |
| ABS / ASA | 耐热、耐候（ASA）或工程原型 | 收缩翘曲、层裂、气味 / 挥发物、通风 | 先完成 PLA 基线，再建立通风、干燥与小试样流程 |
| TPU 等柔性料 | 缓冲、脚垫、软连接 | 料路阻力、速度过高、AMS 兼容性 | 通常从外置料架和慢速预设开始 |
| 纤维增强 / 改性料 | 刚度、耐热或特定性能 | 磨蚀喷嘴、吸湿、脆性、厂商限制 | 先查 TDS 对喷嘴材质、孔径、干燥与安全的要求 |

> [!tip] 45° 是筛查悬垂的经验起点，不是绝对规则
> 是否需要支撑还与材料、层高、冷却、桥接跨度和模型截面有关。正确动作是切片后检查每一层的路径，而不是仅凭模型的视觉角度判断。

### 三、拓竹生态：软件、模型、设备和支持如何协作

| 组成 | 作用 | 新手应掌握的边界 |
| --- | --- | --- |
| P1S 打印机 | 将切片后的任务实际执行；封闭机箱有利于 ABS / ASA 等材料的热环境 | 不负责判断材料是否受潮、模型是否适合打印 |
| AMS（若有） | 多色 / 多材料自动换料、料槽管理和相对密封存放 | 不是通用干燥机；第三方线轴与柔性料要先确认兼容性 |
| Bambu Studio | 导入模型、设置材料与工艺、切片预览、发送和设备管理 | 软件预设是起点，不是每卷陌生耗材的最终参数 |
| Bambu Handy | 手机查看状态、相机、通知和基础控制 | 远程监控不能替代首层观察与现场安全条件 |
| MakerWorld | 获取模型、3MF 项目和社区经验 | 模型带的参数是作者环境的样本，必须核对再用 |
| 官方耗材 / 第三方耗材 | 提供不同的性能、颜色与成本选择 | 原厂 RFID / 预设带来便利；第三方也能用，但需正确建立自定义耗材副本 |

建议的学习顺序是：先用干燥的 PLA/PETG 跑通“模型—切片—预览—首层—取件”闭环；再学习其他工程耗材、支撑与尺寸配合；最后进入 ABS / ASA、柔性料和填充增强材料。不要用高难度材料的失败来学习最基础的切片操作。

#### 3.1 从 MakerWorld 下载项目时，先问这五个问题

1. 作者使用的打印机、喷嘴和板材是否与当前设备一致？
2. 每个颜色实际映射到哪种材料？多色项目的“颜色一样”不等于材料可以互换。
3. 模型是否有作者写明的强度、安装方向、后处理或硬件要求？
4. 预览后，支撑、首层面积、冲刷塔和估算耗材是否符合预期？
5. 这个项目是否保存为自己的副本，便于回溯后来改过什么？

3MF 项目的价值是传递上下文，不是替你承担责任。特别是公共打印机上，先复制项目、改成当前设备的材料与板材，再切片预览；不要直接信任“作者能打成功，所以我一定能打成功”。

#### 3.2 一次任务在拓竹生态中的正确信息流

~~~text
模型来源 / 自己建模
        ↓（保留说明与版本）
Bambu Studio：P1S + 喷嘴 + 板材 + 耗材 + 工艺
        ↓（切片、预览、保存 3MF）
设备与 AMS：实际装料、状态、首层执行
        ↓（照片、尺寸、异常信息）
自己的耗材档案 / 维护记录 / 官方支持资料
        ↓
下一次打印只改变一个可解释的变量
~~~

这条链路的核心是**可追溯**：成功件要能找到当时的 3MF、耗材和板材；失败件同样要能找到报错、预览、第一层照片和已做操作。否则“这台机器有时能打、有时不能打”无法变成可复用的经验。

### 四、打印机结构介绍：知道每个部件会在哪类问题里出现

P1S 是封闭式 CoreXY FDM 打印机。官方资料将其定位为适合 PLA、PETG、TPU、PVA、ABS 与 ASA 等多种材料的机型；具体可用材料仍取决于喷嘴、耗材预设、环境与维护状态。其最大构建体积为 256 × 256 × 256 mm，热端最高温度为 300 °C；这些能力说明它适合进阶材料，但不等于每种高温 / 磨蚀材料均可直接使用。

| 部件 | 它做什么 | 日常检查与新手边界 |
| --- | --- | --- |
| 热端、喷嘴与硅胶套 | 加热、熔化并挤出材料；喷嘴直径影响细节与速度 | 观察是否有积料、硅胶套是否完整；更换热端按官方指南，先断电并充分冷却 |
| 挤出机与进料路径 | 抓住线材并持续送入热端 | 出现打齿、异响或欠挤，先检查线材、PTFE 管和堵头，不要先乱改流量 |
| 工具头与切刀 / 擦嘴机构 | 承载热端，完成换料后的切断与清洁动作 | 清理废料和擦嘴区域；不在机器运动时伸手进入 |
| PEI 打印板与热床 | 提供附着、加热和可弯曲取件表面 | 保持无油；用对板材与材料合适的胶 / 隔离层；冷却后再取件 |
| X/Y 碳杆、皮带与滑轮 | 让工具头高速、准确地在 XY 平面运动 | 只按官方方法清洁；碳杆不要随意上油，皮带不要凭感觉频繁调紧 |
| Z 丝杆与升降机构 | 带动热床上下移动，决定层高稳定性 | 根据官方维护要求清洁和润滑；发现异响、卡顿再排查 |
| 部件冷却、辅助风扇、腔体 / 主板散热 | 控制模型冷却和设备散热 | 不遮挡进出风口；风扇异响或不转需停机排查 |
| 活性炭滤芯与排风路径 | 降低部分气味与颗粒物 | 是辅助措施，不替代通风；按官方说明更换耗材件 |
| AMS、干燥剂与 PTFE 管（Combo） | 自动送料、换色和料路连接 | 保持线材路径顺直；定期看干燥剂与 PTFE 磨损；不兼容耗材改走外置料架 |

> [!note] 喷嘴与材料的兼容性
> 原厂配置的喷嘴并不意味着适合所有填充型线材。碳纤、玻纤、金属等磨蚀性填料会加速喷嘴和挤出齿轮磨损；使用前先看耗材厂商对喷嘴材质、最小孔径和干燥条件的要求，再决定是否升级硬化部件。

#### 4.1 用「料路—热端—运动—热环境」四条线理解结构

~~~text
AMS / 外置料架 → PTFE 管 → 挤出机 → 热端 → 喷嘴 → 打印件
                                  ↑
              打印板 / 热床 ← 模型的首层附着与温度
                                  ↑
X/Y 碳杆、皮带、滑轮 → 工具头定位；Z 丝杆 → 热床升降
                                  ↑
部件风扇、辅助风扇、腔体排风、主板散热 → 成型与设备温度
~~~

| 现象先出现在哪里 | 优先沿哪条线检查 | 不应直接做的事 |
| --- | --- | --- |
| 断料、打齿、欠挤、换色失败 | 料卷 / AMS → PTFE → 挤出机 → 热端 / 喷嘴 | 先把流量和温度大幅拉高 |
| 首层不粘、边角翘起、底面脏 | 打印板 → 热床 → 材料干燥 / 环境 → 切片附着策略 | 用力压住模型或带着翘边继续打 |
| 图层错位、撞击、异响 | 模型是否翘起 → 工具头路径 → 皮带 / 滑轮 / 运动机构 | 在未确认原因时频繁调皮带或涂油 |
| 悬垂糊、桥接坠、局部软塌 | 切片方向 / 支撑 → 材料预设 → 冷却风扇 | 只盲调全局速度，不预览模型结构 |

#### 4.2 对 AMS 的正确期待

AMS 擅长的是自动选料、换色、换卷与相对密封存放。它不负责把已经吸湿的耗材烘干，也不保证每个第三方线轴、软料或易碎料都能顺畅走料。发现送料阻力时，先检查线轴是否能平稳转动、线材是否缠绕、PTFE 管是否折弯、槽位材料是否正确；如果耗材不兼容，不要强行使用，而是改走外置料架并在切片中匹配该材料。

### 五、Bambu Studio：从模型到可执行任务

#### 5.1 先分清三类预设，避免“改错地方”

| 预设 | 控制什么 | 典型内容 | 何时建立副本 |
| --- | --- | --- | --- |
| 打印机预设 | 硬件边界 | P1S、喷嘴直径、可用体积、设备能力 | 更换喷嘴或使用不同设备时 |
| 耗材预设 | 材料如何熔化与冷却 | 喷嘴 / 热床温度、风扇、流量、最大体积流量 | 新品牌、新颜色、新批次或陌生改性料时 |
| 工艺预设 | 这个模型如何被制造 | 层高、墙数、填充、速度、支撑、Brim | 目标从外观件变为承力件，或模型结构不同的时候 |

系统预设保留为基线。对第三方或陌生材料，从最接近的官方 / Generic 预设复制一份，以“品牌—材料—颜色—喷嘴—日期”命名；不要直接覆盖系统预设，也不要把所有线材塞进同一个“万能料”配置。

#### 5.2 一次完整的切片流程

1. **新建项目并选设备**：选择 P1S、实际喷嘴尺寸和实际打印板。型号、喷嘴和板材错一个，后续温度、首层和可打印尺寸都可能失真。
2. **导入模型**：优先保留 3MF 项目中的模型和作者说明；导入 STL 时检查单位是否正确，出现“极小 / 极大”模型先回到建模软件确认单位。
3. **确认耗材映射**：单色件确认实际 AMS 槽位或外置料架；多色件逐色检查颜色、材料与换料量。不要只看屏幕颜色而忽略材料类型。
4. **摆放与方向**：让最稳定的大平面接触热床；思考外观面、承力方向、支撑痕迹和层纹方向。长条承力件若主要受 Z 向剥离，通常比平放更脆弱。
5. **选择工艺**：初学者先从 0.20 mm 标准层高、对应材料的官方预设开始。需强度时优先考虑壁数、方向和圆角，再考虑提高填充；需外观时再考虑更小层高和支撑痕迹。
6. **设置支撑与附着**：支撑只为真实悬空区域服务；Brim 用于改善翘边风险。增加支撑、Raft 或填充不是默认“更稳”，它们也会增加耗材、时间和后处理风险。
7. **切片并预览**：在 Preview 中逐层滑动，检查首层轮廓、外墙、薄壁、支撑接触面、空中打印路径、换色 / 冲刷位置和打印顺序。预览是发现错误的最后低成本环节。
8. **发送前复核**：核对打印机、耗材、板材、模型数量、预计时间与耗材消耗；保存 3MF，保证以后能回看当时的设置。

#### 5.3 预览时优先看什么

| 观察点 | 正常信号 | 需要停下来修改的信号 |
| --- | --- | --- |
| 首层 | 连续的轮廓与填充，底面积合理 | 小脚、悬空首层、极窄接触面、没有附着辅助却很易翘边 |
| 外墙 / 薄壁 | 关键壁面有连续路径 | 壁被省略、孔被堵、细杆只剩零散路径 |
| 支撑 | 承接真正的悬垂，接触面可拆 | 大面积贴在外观面、支撑无法落到热床 / 模型上 |
| 换色 | 槽位与材料类型正确，冲刷位置合理 | 将 ABS 与 PLA 等不相容组合在承力结合界面、冲刷到不该出现的位置 |
| 时间与用料 | 作为成本估算 | 估算异常飙升时，回查层高、支撑、填充、模型是否重复 |

#### 5.4 一个新手先不要跳过的「最小可用设置」

第一次不需要理解所有高级参数，但以下项目必须明确：

| 设置 | 首次打印的建议 | 为什么不能跳过 |
| --- | --- | --- |
| 打印机与喷嘴 | 选实际 P1S 和实际安装的喷嘴直径 | 错喷嘴会让线宽、层高限制和耗材预估都不可信 |
| 打印板 | 选实际板材类型，并确保装在机器上 | 影响首层温度、附着策略与清洁方式 |
| 耗材 | 选实际材料类型、品牌 / Generic 副本和颜色；AMS 时选实际槽位 | 决定热端温度、热床、风扇和换料行为 |
| 层高与工艺 | 从标准层高与对应材料预设开始 | 给故障诊断一个可重复的基线 |
| 摆放 | 大接触面优先，同时兼顾受力和外观面 | 直接影响翘曲、强度、支撑和表面质量 |
| 支撑与 Brim | 只因模型结构或材料收缩风险而启用 | 两者都会增加后处理与耗材，不是默认必选项 |

参数调整前先写一句假设，例如“这卷 PETG 已干燥，但桥接下垂，所以仅测试桥接速度 / 风扇设置”。没有假设地同时改温度、速度、流量、墙数和支撑，得到的成功或失败都难以解释。

#### 5.5 对陌生耗材建立副本的最短路径

1. 找到最接近的官方或 Generic 材料预设，**复制**而不是覆盖系统预设。
2. 用“品牌—材料—颜色—喷嘴—日期”命名；将 TDS、干燥条件和购买批次记录在自己的耗材笔记。
3. 先检查干燥、料路和板材，再打印小型测试件；不要一开始就打十小时的大件。
4. 若确实出现流量或压力相关的稳定缺陷，再使用 [官方流量动态校准](https://wiki.bambulab.com/en/software/bambu-studio/calibration_pa) 与 [流量比校准](https://wiki.bambulab.com/en/software/bambu-studio/calibration_flow_rate) 建立材料副本。
5. 保存 3MF、结果照片与只修改过的变量。校准是为了让某卷材料可复现，不是为了追求一组“放之四海皆准”的数值。

### 六、完整的切片到收菜流程：新人首次打印照着做

```text
打印前：模型与材料确认 → 板面清洁 → 线材干燥 / 装料 → 切片与预览
启动：设备自检 / 调平 → 加热 → 出料与擦嘴 → 首层观察
打印中：远程或现场观察 → 只在必要时暂停 / 取消 → 保持周边安全
结束后：冷却 → 取下打印板 / 取件 → 外观、尺寸与强度检查 → 保存项目与记录
```

#### 6.1 打印前检查清单

- [ ] 设备周边无易燃物，风道未被遮挡；高温 / 有气味材料已有通风方案。
- [ ] 打印板干净、装到位，且切片中的板材类型与实际一致。
- [ ] 耗材干燥、走料顺畅；AMS 槽位或外置料架与切片材料一致。
- [ ] 热端、硅胶套、擦嘴和排废槽无明显积料、断丝或堵塞。
- [ ] Bambu Studio 已选对 P1S、喷嘴、模型数量、材料和工艺预设。
- [ ] 已在 Preview 检查首层、支撑、薄壁和换色路径。

#### 6.2 首层是最值得现场看的阶段

首层通过后，绝大多数“参数 / 模型 / 板面”问题才会降低风险。重点看线条是否均匀压实、是否堆在喷嘴上、边角是否抬起、是否有异常摩擦或送料声。发现明显失败时，尽早取消任务比让机器继续制造一团积料更安全也更省耗材。

打印中不要把手、工具或衣物伸入运动范围；不要在没有基本安全条件的情况下长时间无人看管。出现冒烟、异常焦味、持续撞击、线缆拖拽、热端大面积积料或安全报警时，先停止任务；按官方故障说明进行后续处理，必要时关闭电源并联系官方支持。

#### 6.3 结束、取件与质量确认

等待热床和模型充分冷却后，再取下柔性打印板并轻微弯曲取件；不要在高温时暴力撬动，避免伤到板面或变形。取件后检查：

| 项目 | 怎么看 | 下一步 |
| --- | --- | --- |
| 首层与底面 | 是否完整、无大面积象脚、无脱层 | 调整板材 / 首层 / 温度前先确认板面清洁 |
| 外观 | 拉丝、鼓包、接缝、悬垂和支撑痕 | 保留照片，关联到耗材与预设 |
| 尺寸 | 用卡尺量关键孔、轴、配合面 | 不要只凭一个外尺寸就大改 XY 补偿 |
| 结构 | 按真实受力方向轻度测试层间结合 | 承力件先打小试样，再改变方向 / 壁数 / 材料 |
| 可复现性 | 保存 3MF、耗材信息和最终预设 | 成功一次不等于所有模型都适用 |

#### 6.4 首次打印的逐步执行卡

1. **到机器前**：确认设备允许使用、没有其他任务，周边没有可燃物；检查打印板、排废槽与热端周围是否干净。
2. **准备耗材**：确认线材没有明显缠绕、脆断或吸湿迹象。若用 AMS，逐槽核对实际线材和软件材料；若外置供料，确认料架转动顺畅、PTFE 管没有被压折。
3. **清洁与装板**：按该板材的官方说明清洁、擦干并正确装入。尽量只拿板边，不再触摸有效打印区域。
4. **在 Studio 打开项目**：选择 P1S、实际喷嘴与板材；导入模型后检查单位、是否落在打印板上和是否超出边界。
5. **完成切片**：指定材料与工艺，设置合理朝向、必要的支撑 / Brim；切片后在预览中检查首层、薄壁、悬垂、支撑和模型数量。
6. **发送前最后确认**：估算时间与耗材是否合理，保存 3MF 副本；再确认目标设备是当前这台 P1S，而不是网络中的另一台机器。
7. **启动并看首层**：在设备完成加热、调平和擦嘴后，留在现场观察首层轮廓与填充。线条明显堆料、拖拽、脱落、撞击或异响时，及时取消并记录。
8. **打印中**：保持箱门、风道和周边状态符合当前材料的要求；远程监控只能辅助，不能代替危险材料或异常任务的现场判断。
9. **结束后收菜**：等热床与模型冷却，取下打印板、轻弯取件；清理裙边、支撑和废料，检查打印板是否受损，再把材料收好。
10. **验收并记录**：拍首层 / 外观 / 关键尺寸照片，保存最终 3MF；若失败，先记录现象和条件，下一次只改一个有理由的变量。

> [!warning] 何时必须立即停止
> 明显的热端大面积积料、冒烟或焦味、持续撞击、线缆被牵拉、风扇异常停转、无法解释的加热报错，都不是“再观察一会儿”的场景。应先停止任务，必要时按官方安全与支持说明断电并交接。

### 七、日常使用：把失败挡在点击「打印」之前

#### 材料、门盖与环境

- 各耗材的温度、风扇、干燥和是否关闭门盖，以材料厂商 TDS 与对应预设为准。封闭机箱对 ABS / ASA 有价值，但对部分长时间 PLA 打印可能需要按预设和实际温度避免热端热堆积。
- 远离空调直吹、敞开窗缝、潮湿环境和阳光直晒；环境波动会放大翘边、层间裂纹和尺寸波动。
- 线材开封后密封保存，配干燥剂和湿度计；遇到爆裂声、气泡、拉丝突然加重或表面麻点，先排除受潮再调参数。

#### 打印板与附着

- 首层问题先清洁板面。根据板材说明使用推荐清洁方法；手指油脂、残胶和灰尘都会降低附着。
- 胶的作用可能是增强附着，也可能是作为隔离层保护板面；不能把“多涂胶”当作所有首层问题的解法。
- 不用刀尖在板面上硬撬；若反复难取件，重新检查板材、材料和冷却，而不是持续加大蛮力。

#### 文件、网络与远程控制

- 关键项目保存本地 3MF；它比只保存 STL 更能保留模型摆放、耗材和切片上下文。
- 开启局域网或云端功能前，理解其网络边界；网络不稳定时可改用官方支持的本地 / 存储卡流程。
- 固件与 Bambu Studio 升级前，重要项目先保存副本；若新版本改变了预设、切片结果或设备连接，回到官方发布记录核验，不要凭社区片段盲目回退或改配置。

#### 公共打印机的交接信息

每次结束至少应留下：当前打印板状态、剩余耗材与槽位、是否有待清理废料、是否出现异常、最后一次成功项目的位置。若任务失败，除照片外还应写明材料、喷嘴、板材、切片预设、是否使用 AMS、开始时首层表现和屏幕上的完整错误文字。这个信息比一句“机器坏了”更能帮助下一位使用者恢复设备。

### 八、日常维护：按风险与官方周期分层做

> [!warning] 维护的前提
> 清洁、润滑、拆热端或进入工具头前，通常应关机、断电并等待热端与热床冷却。唯一例外是官方步骤明确要求在加热状态下操作的项目；此时严格遵循该步骤的防烫与工具要求。没有对应官方指南时，不做深度拆机。

| 触发时机 | 维护对象 | 可做的基础动作 | 不要做什么 |
| --- | --- | --- | --- |
| 每次打印前后 | 打印板、喷嘴周围、排废槽 | 清掉碎屑与排出的废料；观察喷嘴 / 硅胶套 | 热端未冷却时徒手清理；用硬物刮喷嘴 |
| 首层变差或板面有污 | PEI 板 | 按板材官方说明清洁并完全干燥 | 把强溶剂、研磨剂或金属刮刀当作通用清洁方案 |
| 积累一定打印时长或出现异响 | X/Y 运动机构、Z 丝杆、皮带 | 按 P1 维护页的对象和步骤清洁 / 润滑 | 给碳杆随意上油；未诊断就反复张紧皮带 |
| 风量异常、噪声变大 | 各风扇与风道 | 断电冷却后清除可见灰尘 | 遮挡风道继续打印，或对风扇直接灌润滑油 |
| 欠挤、打滑、送料异常 | 挤出机、PTFE 管、热端 | 先检查线材、料路、喷嘴和官方清洁指引 | 先把流量比大幅调高，掩盖机械问题 |
| 多色失败或送料阻力大 | AMS、干燥剂、PTFE 管、线轴 | 核对线轴尺寸、槽位、干燥剂和走料路径 | 用脆弱 / 软料强行走 AMS |
| 固件 / 软件更新后异常 | 设备配置与项目文件 | 保存版本、预设与现象，查发布记录 | 删除所有预设或恢复出厂设置来碰运气 |

#### 8.1 把维护分成三种频率

- **每次任务的清洁**：处理废料、检查打印板和喷嘴外观。这是使用者的日常职责，能预防绝大多数首层与异物问题。
- **按打印时长或官方提示的例行维护**：运动机构、Z 丝杆、风扇、滤芯、AMS 干燥剂等。周期以 [P1 系列维护指南](https://wiki.bambulab.com/en/p1/maintenance) 和设备实际使用强度为准；团队设备建议由负责人维护并登记。
- **由现象触发的维护**：持续异响、反复欠挤、送料异常、风量变化、热端积料等。先记录现象，再打开对应官方指南；不要因为“很久没维护”就把整机拆开。

#### 8.2 清洁与润滑的常见边界

| 对象 | 正确原则 | 需要避免的误操作 |
| --- | --- | --- |
| PEI 打印板 | 以当前板材官方说明的清洁方式为准，清洁后完全干燥 | 在板面上使用不明溶剂、用刀尖暴力铲件 |
| 碳杆 | 保持清洁，按官方说明处理 | 把润滑油涂到碳杆上；油污会吸附灰尘并影响运动 |
| Z 丝杆 | 只在官方步骤要求时，使用指定位置和方式清洁 / 润滑 | 润滑剂随意涂到皮带、打印板或电子部件 |
| 喷嘴与硅胶套 | 冷却后清除外部可见残料；积料时按热端官方处理流程 | 热端高温时徒手拔料，或用金属工具猛撬加热块 |
| 风道与风扇 | 断电冷却后清除可见灰尘，确认没有异物 | 遮挡风口、对电子设备喷入液体或把风扇当作可随意拆洗部件 |

- 日期：
- 累计打印时长（设备页）：
- 触发原因：例行维护 / 首层变差 / 异响 / 欠挤 / AMS 送料异常

### 九、报错与异常处理：先分级，再定位，不盲目改参数

#### 9.1 先看风险等级，再决定是否继续排查

| 等级 | 典型信号 | 立即动作 |
| --- | --- | --- |
| A：安全 / 硬件风险 | 冒烟、焦味、加热异常、线缆损伤、持续撞击、工具头大面积积料、风扇不转 | 停止任务；必要时按官方安全说明关机 / 断电；拍照并交给负责人或官方支持 |
| B：可能伤机或扩大失败 | 模型已脱落却被喷嘴拖着打、明显翘起顶到喷嘴、送料持续打齿、AMS 反复失败 | 尽早取消；冷却后检查，保留任务和现象记录 |
| C：打印质量问题 | 拉丝、接缝、表面粗糙、轻微翘边、桥接差、尺寸偏差 | 可以完成小测试或暂停复核；每次只验证一个假设 |

> [!warning] 先停机的情况
> 出现 A 级现象时，不要为了“省一点耗材”让机器继续运行，更不要在通电、高温或运动中把手伸进机箱。本文只提供定位框架；涉及拆机、热端、传感器、电机、电气与错误代码的具体处理，优先使用 [P1 系列官方支持中心](https://bambulab.cn/zh-cn/support/804378512629276672) 的对应页面。

#### 9.2 统一排查顺序：建立基线，而不是同时乱改

1. **冻结现场**：截图或抄录屏幕上的完整错误文字，拍首层 / 失败部位 / 料路照片；保存当前 3MF 和软件、固件版本。
2. **区分范围**：同一模型每次都失败，优先看模型和切片；只有某卷料失败，优先看该耗材；所有材料都失败，优先看板面、料路、热端和设备状态。
3. **回到最小基线**：用状态良好的 PLA、已知正常的 0.4 mm 喷嘴、干净板面和小基准模型验证。基线失败时，不先对特定材料做复杂调参。
4. **一次只改一个变量**：例如只清洁板面、只更换干燥料、只调整摆放或只更改支撑；保留前后照片和切片预览。
5. **验证与升级**：小测试正常后再恢复原模型；若出现硬件风险、重复失败或操作超出授权，停止并交接。

#### 9.3 按现象处理常见成型问题

| 现象 | 常见成因类别（不是唯一原因） | 先做的低风险检查 | 下一步与禁止动作 |
| --- | --- | --- | --- |
| 首层线条不粘、被喷嘴拖走 | 板面油污、板材 / 预设不匹配、材料状态、模型接触面太小 | 清洁并擦干打印板；核对板材、材料、首层预览与装板状态 | 仍失败再用基线模型；不要在运行中用手压住模型 |
| 边角翘起或整件脱落 | 材料收缩、冷风、板面状态、接触面积不足 | 检查环境波动、板面、摆放和 Brim 是否合理 | 对 ABS / ASA 先处理通风与热环境；不要让翘起件持续撞喷嘴 |
| 底部扩张（象脚） | 首层受压 / 热环境、模型设计或补偿设置 | 判断是否影响装配，仅对关键尺寸做测量 | 不要因一个非关键外观面就全局大改尺寸补偿 |
| 拉丝、渗料、表面有细丝 | 耗材受潮、温度 / 回抽 / 移动、模型路径 | 先确认材料干燥，再看材料预设和预览移动路径 | 不要把温度一次降很多而导致层间结合不足 |
| 层间裂开、容易沿层掰断 | 温度、冷却、材料受潮、环境波动、受力方向 | 检查材料 TDS、干燥、门盖 / 风扇策略和摆放方向 | 承力件先打小样验证；不要只靠加满填充补救 |
| 表面缺料、间断、孔洞 | 线材阻力、受潮、部分堵头、挤出机打滑、流量不适配 | 观察料卷、PTFE、挤出声音和喷嘴外观；用干燥料做小测试 | 先排料路 / 堵头，再做校准；不要盲目提高流量 |
| 喷嘴周围积料或「一坨料」 | 首层脱落、喷嘴挂料、支撑 / 模型失败 | 立即停止，待冷却后按官方热端清理说明处理 | 不要热端带电时硬拽；积料涉及线缆时交接 |
| 悬垂下垂、桥接塌陷 | 摆放、支撑不足、冷却 / 速度、材料行为 | 在预览中确认是否为真实悬空；用小结构验证支撑或方向 | 不要把所有部位都铺满支撑，先保护关键悬垂 |
| 支撑难拆、接触面很差 | 支撑接触位置、间隙、材料和方向 | 检查支撑是否落在外观面，尝试重摆放 | 先保存一版项目；不要在原版上连续叠加修改 |
| 尺寸不准、孔偏小 | 材料收缩、首层象脚、孔 / 壁的建模尺寸、测量方法 | 测量多个关键点并区分 XY 与 Z；检查设计用途 | 不以一次测量就大幅全局缩放模型 |

关于以上现象的图示与官方分步骤教程，使用 [官方打印质量问题教程](https://bambulab.cn/zh-cn/support/860876060669231104)。官方页面会更新，屏幕错误代码、热端与部件更换流程则以 P1 专项支持页为准。

#### 9.4 送料、AMS 与设备类异常

| 现象               | 先检查                                           | 何时停止并交接                          |
| ---------------- | --------------------------------------------- | -------------------------------- |
| AMS 无法进料 / 退料    | 实际槽位、线轴能否自由转动、线材是否缠绕或断裂、PTFE 管是否折弯、材料是否适合 AMS | 连续失败、线材卡在设备内部、需要拆工具头或不确定料路位置     |
| 挤出机打齿 / 咔嗒声      | 料卷阻力、耗材脆断或受潮、喷嘴是否疑似堵塞、是否选错材料温度                | 清除简单可见阻塞后仍持续，或需要拆挤出机 / 热端        |
| 任务无法发送或设备离线      | 设备电源与网络状态、目标打印机是否选对、软件与固件发布记录                 | 反复连接失败、升级后异常且没有明确官方恢复步骤          |
| 打印中层移、撞击或持续机械异响  | 模型是否翘起导致碰撞、是否存在明显障碍物、任务预览是否异常                 | 取消后仍有异响、皮带 / 电机 / 工具头状态可疑、需要机械调校 |
| 加热、风扇、传感器或其他屏幕报错 | 记录完整错误码 / 文本、设备版本、发生时机                        | 此类报错默认不靠调切片修复；按官方对应说明或工单处理       |

### 十、建议的新手进阶路线

| 阶段 | 练习目标 | 推荐产出 | 通过标准 |
| --- | --- | --- | --- |
| 第一次开机 | 跑通首个官方 / 简单模型 | 一份保存好的 3MF | 能完成预览、首层观察、冷却取件 |
| 基础切片 | 理解摆放、层高、墙、填充、支撑 | 同一模型的外观版与强度版 | 能解释两版参数与结果的差异 |
| 材料管理 | 建立每卷耗材身份和存储记录 | PLA / PETG 各一个自定义副本 | 知道材料、板材、干燥与预设的关系 |
| 尺寸与装配 | 打印卡尺测试件、孔 / 轴配合样件 | 一组可装配样件 | 能用测量结果指导下一次修改 |
| 进阶材料 | 在安全条件下学习 ABS / ASA 或改性料 | 小测试件、校准记录 | 能先处理环境和干燥，再做流量校准 |
| 维护与排障 | 记录维护、建立 PLA 基线 | 一份维护记录与排查案例 | 不靠同时改多个参数“碰运气” |
