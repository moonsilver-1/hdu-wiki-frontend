## 下载安装

前往 [obsidian.md](https://obsidian.md) 下载对应平台的安装包。支持 Windows、macOS、Linux、iOS、Android。

**免费使用**。截至 2026-09-14，商业用途也不再强制购买商业许可证（官方自 2025-02-20 起改为可选），以官方为准。

## 创建 Vault

启动后点击「Create new vault」：

1. 输入 Vault 名称（如 `MyBrain`）
2. 选择存储位置
3. 点击创建

**Vault 就是一个本地文件夹**，里面所有文件都是 `.md` Markdown 文件，你随时可以用其他编辑器打开。

## 第一条笔记

1. 点击左侧「New note」或按 `Ctrl/Cmd + N`
2. 输入标题和内容
3. 自动保存，不需要手动保存

```markdown
## 我的第一条笔记

今天开始用 Obsidian 管理知识。

想要学习的：
- [[Zettelkasten 方法]]
- [[双向链接的用法]]
```

输入 `[[` 时会弹出笔记搜索，选择已有笔记或创建新笔记。

## 核心快捷键

| 快捷键                    | 功能        |
| ---------------------- | --------- |
| `Cmd/Ctrl + N`         | 新建笔记      |
| `Cmd/Ctrl + O`         | 快速打开笔记    |
| `Cmd/Ctrl + P`         | 命令面板      |
| `Cmd/Ctrl + E`         | 切换编辑/预览模式 |
| `Cmd/Ctrl + K`         | 插入链接      |
| `[[`                   | 插入双向链接    |
| `Cmd/Ctrl + Shift + F` | 全局搜索      |

## 推荐设置

打开设置（`Cmd/Ctrl + ,`）：

1. **编辑器 → 默认编辑模式** → 选择「Source mode」或「Live Preview」
2. **文件与链接 → 新建笔记存放位置** → 选「当前文件夹」或「指定文件夹」
3. **外观** → 选一个喜欢的主题
4. **核心插件** → 开启「日记」「模板」「大纲」「图谱视图」
