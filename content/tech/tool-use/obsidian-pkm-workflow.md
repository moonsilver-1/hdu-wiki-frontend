**PKM（Personal Knowledge Management，个人知识管理）** 不只是记笔记，而是一个从**捕获**到**输出**的完整循环。

## 四阶段循环

```
捕获 → 处理 → 组织 → 输出
  ↑                    |
  └────────────────────┘
        持续循环
```

### 1. 捕获（Capture）

**原则：** 快速、低摩擦、不求完美。

| 来源    | 工具                            |
| ----- | ----------------------------- |
| 随时灵感  | 手机备忘录 → 稍后转到 Obsidian         |
| 读书    | 在书中画线 → 写入 Obsidian 文献笔记      |
| 文章    | Readwise / 网页剪藏 → 导入 Obsidian |
| 播客/视频 | 记关键词 → 展开为笔记                  |
| 会议    | 会议笔记模板 → Obsidian             |

**关键：** 捕获阶段不要整理，不要加链接，不要纠结格式。先记下来再说。

### 2. 处理（Process）

**原则：** 用自己的话重述，提炼核心观点。

每天花 **15-30 分钟**处理收集箱里的内容：

1. 打开 Inbox 文件夹
2. 逐条浏览未处理的笔记
3. 问自己：这个想法对我重要吗？
   * 重要 → 用自己的话改写为原子笔记
   * 一般 → 做渐进式总结（Layer 2-3）
   * 不重要 → 删除或归档

### 3. 组织（Organize）

**原则：** 链接优先于分类。

处理完的笔记：

* 添加 **双向链接** — 至少链接 1 条相关笔记
* 添加 **标签** — 2-3 个标签足够
* 更新 **MOC** — 如果属于某个主题，加到对应的 MOC
* 添加 **Properties** — 日期、来源、状态等元数据

### 4. 输出（Output）

**原则：** 知识的价值在于使用。

输出形式：

* 写博客文章
* 做演讲/分享
* 写技术文档
* 做决策时引用笔记
* 教别人

**不要等到"准备好了"再输出。** 有 5 条相关笔记就可以写一篇短文，有 20 条就可以写一篇长文。

## 每日节奏

```
早上（5 分钟）
├── 查看今日日记模板
├── 回顾昨天的闪念笔记
└── 确定今天要处理的笔记

工作中（随时）
├── 随手记录灵感和发现
└── 捕获到 Inbox

晚上（15 分钟）
├── 处理 Inbox 中的笔记
├── 添加链接和标签
└── 更新相关 MOC
```

## 每周回顾

每周日花 30 分钟：

1. **清空 Inbox** — 处理所有未整理的笔记
2. **回顾本周** — 浏览本周创建的笔记，有没有遗漏的链接
3. **浏览图谱** — 在图谱视图中发现新的连接
4. **更新 MOC** — 把新笔记加到合适的 MOC
5. **反思** — 这周学到了什么？对什么感兴趣？

## 避坑指南

1. **别把太多时间花在系统上** — 系统是工具，不是目标
2. **别追求完美** — 80% 的笔记不需要精心打磨
3. **别只收藏不处理** — 未处理的笔记 = 没有价值
4. **别一开始就设计复杂系统** — 从最简单的开始，需要时再加
5. **坚持比完美重要** — 每天 15 分钟比每周 3 小时效果好
