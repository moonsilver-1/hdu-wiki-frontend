Claude Code 可以作为你的写作搭档，帮你在 Obsidian Vault 中起草、润色、扩展和重组内容。

## 起草初稿

### 从笔记到文章

当你积累了足够多的原子笔记，可以让 Claude 帮你组合成文章：

```
我想写一篇关于"个人知识管理"的文章。
先搜索 Vault 中所有和 PKM、知识管理相关的笔记，
然后用这些笔记的内容为基础，起草一篇 2000 字的文章大纲。
把大纲保存到 Output/PKM文章大纲.md
```

Claude 会：

1. 搜索所有相关笔记
2. 理解每条笔记的核心观点
3. 组织成文章结构
4. 生成大纲

### 从大纲到全文

```
根据 Output/PKM文章大纲.md 中的大纲，
结合 Vault 中引用的那些笔记的详细内容，
展开写成一篇完整的文章。
保持我在 Vault 中写笔记的语言风格。
```

## 润色修改

### 单篇润色

```
读一下 Cards/教别人是最有效的学习方式.md，帮我：
1. 语言更精炼（不改变核心意思）
2. 检查是否有逻辑跳跃
3. 建议可以补充的链接
```

### 批量润色

```
检查 Cards/ 文件夹中最近 10 条笔记的写作质量：
1. 标题是否是断言式的？
2. 内容是否自洽？
3. 是否有冗余表达？
列出需要修改的笔记和具体建议
```

## Zettelkasten 辅助

### 从文献到永久笔记

```
读一下 Literature/思考快与慢.md 这篇文献笔记，
从中提取 3-5 个独立的观点，
为每个观点创建一张永久笔记在 Cards/ 文件夹下。
要求：
- 断言式标题
- 用我自己的话重述（不是照抄原文）
- 添加 frontmatter
- 链接到已有的相关笔记
```

### 发现连接

```
读一下 Cards/习惯的复利效应.md，
搜索 Vault 中所有可能和这个概念相关但还没有链接的笔记，
建议添加哪些双向链接
```

## 翻译

### 笔记翻译

```
把 Cards/减少决策数量比提升决策质量更有效.md 翻译成英文，
保持 frontmatter 格式，保留所有 [[双向链接]]，
保存到 Cards-EN/ 文件夹下
```

### 批量翻译

```
把 Cards/ 文件夹下所有带 #分享 标签的笔记翻译成英文，
保存到 Cards-EN/ 对应的文件中
```

## 摘要生成

### 为长笔记添加摘要

```
找出 Vault 中超过 500 字的笔记，
为每篇在 frontmatter 中添加一个 summary 字段，
用一句话概括核心内容
```

### 生成每日摘要

```
读取今天的日记和所有今天修改过的笔记，
生成一段 3-5 句话的每日知识摘要，
追加到今天的日记末尾
```

## 问答检索

把 Vault 当作你的个人知识库，向 Claude 提问：

```
根据我 Vault 中的笔记，解释一下"渐进式总结"
和"Zettelkasten"方法的区别和联系。
引用具体的笔记来支撑你的回答。
```

Claude 会搜索 Vault，找到相关笔记，然后基于**你自己的笔记**来回答，而不是通用的互联网知识。

## 写作工作流

```
1. 日常 → 积累原子笔记（Zettelkasten）
2. 想写文章时 → Claude 搜索相关笔记
3. Claude 起草大纲 → 你调整结构
4. Claude 展开全文 → 你润色修改
5. 发布 → 把最终版存入 Output/ 文件夹
```

**AI 是工具，不是作者。** 你的原子笔记是真正的素材库，AI 帮你高效组合，但思考和判断是你的。
