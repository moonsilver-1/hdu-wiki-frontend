**Shadowrocket**（小火箭）是 iOS 平台最流行的代理客户端，功能强大、操作简单。

## 购买与安装

Shadowrocket 是付费应用（截至 2026-09-14 美区 App Store 标价 $2.99，以商店页为准），需要**非中国区 Apple ID** 才能购买。

### 获取非中国区 Apple ID

1. 在 Apple 官网注册一个新的 Apple ID
2. 地区选择美国或其他非中国区
3. 可以用支付宝或礼品卡付款
4. 在 App Store 登录该账号，搜索 Shadowrocket 下载

> 注意：不要在「设置 → Apple ID」中登录，只在 App Store 中切换账号。

## 添加节点

### 方式一：订阅链接（推荐）

1. 打开 Shadowrocket
2. 点击右上角 `+`
3. 选择「类型」为 `Subscribe`
4. 在 URL 栏粘贴机场提供的订阅链接
5. 点击「完成」

节点列表会自动加载。

### 方式二：手动添加

1. 点击右上角 `+`
2. 选择协议类型（VMess / VLESS / Trojan 等）
3. 填写服务器地址、端口、密码等信息
4. 点击「完成」

### 方式三：扫描二维码

1. 点击左上角扫描图标
2. 扫描节点二维码
3. 自动识别并添加

## 基本使用

### 连接代理

1. 在首页选择一个节点（点击节点名称切换）
2. 点击顶部开关启用
3. 首次使用会弹出 VPN 权限请求，允许即可

### 切换节点

直接点击不同节点名称即可切换，无需断开再连。

### 测试延迟

1. 点击「连通性测试」
2. 查看各节点延迟
3. 选择延迟最低的节点

## 路由模式

在首页「全局路由」中选择：

| 模式     | 说明                |
| ------ | ----------------- |
| **配置** | 按规则分流（推荐日常使用）     |
| **代理** | 所有流量走代理           |
| **直连** | 所有流量直连            |
| **场景** | 根据 Wi-Fi 网络自动切换配置 |

## 分流规则配置

### 使用远程规则

1. 进入「配置」页面
2. 点击右上角 `+` 添加远程配置
3. 输入规则集 URL（机场通常会提供）
4. 下载后点击使用

### 常用规则集

一般包含以下分流逻辑：

* 国内网站 → 直连
* 被墙网站 → 代理
* 广告域名 → 拦截
* 苹果服务 → 直连
* 局域网 → 直连

## 进阶功能

### HTTPS 解密

可以解密 HTTPS 流量，用于调试或重写请求：

1. 设置 → HTTPS 解密 → 开启
2. 安装并信任 CA 证书
3. 在「设置 → 通用 → 关于 → 证书信任设置」中启用

### URL 重写

支持 URL 重写规则，可用于去广告、修改请求：

```
^https?://ads\.example\.com reject
```

### 脚本

支持 JavaScript 脚本，可实现复杂的请求修改逻辑。

### 按需连接

设置 → 按需连接 → 开启

启用后，当访问需要代理的网站时自动连接 VPN，平时保持断开，省电。

## 更新订阅

1. 首页 → 长按订阅节点组
2. 选择「更新」
3. 或设置自动更新间隔

## 常见问题

### 连接后无法上网？

1. 检查节点是否可用（测试延迟）
2. 检查路由模式是否正确
3. 尝试切换其他节点
4. 更新订阅获取最新节点

### 提示「VPN 配置无效」？

删除 VPN 配置后重新添加：设置 → VPN → 删除 → 重新打开 Shadowrocket 连接。

### 耗电量大？

* 开启「按需连接」减少后台运行
* 使用规则模式代替全局代理
