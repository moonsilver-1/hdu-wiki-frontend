Obsidian 的插件生态极其丰富，以下是按类别精选的必装插件。

> 截至 2026-09-14，Calendar、Mind Map、Charts、Folder Note、Banners、Remotely Save 的 GitHub 仓库已超过一年没有新提交，安装前先看一眼插件页的更新时间。

## 核心增强

| 插件            | 功能                    | 推荐度   |
| ------------- | --------------------- | ----- |
| **Dataview**  | SQL-like 查询笔记，动态列表/表格 | ⭐⭐⭐⭐⭐ |
| **Templater** | 高级模板引擎，支持 JS 脚本       | ⭐⭐⭐⭐⭐ |
| **QuickAdd**  | 快速捕获、宏、模板触发           | ⭐⭐⭐⭐⭐ |
| **Tasks**     | 全局任务管理、查询、截止日期        | ⭐⭐⭐⭐  |
| **Calendar**  | 日历视图，快速创建日记           | ⭐⭐⭐⭐  |

## 写作与编辑

| 插件                      | 功能               |
| ----------------------- | ---------------- |
| **Editing Toolbar**     | 可视化编辑工具栏         |
| **Outliner**            | 大纲快捷操作（缩进/移动/折叠） |
| **Various Complements** | 自动补全（单词、链接、标签）   |
| **Linter**              | Markdown 格式自动修正  |

## 可视化

| 插件             | 功能            |
| -------------- | ------------- |
| **Excalidraw** | 内嵌手绘白板        |
| **Mermaid**    | 流程图/时序图（内置支持） |
| **Kanban**     | 看板视图          |
| **Mind Map**   | 思维导图          |
| **Charts**     | 图表渲染          |

## 组织与导航

| 插件               | 功能             |
| ---------------- | -------------- |
| **Tag Wrangler** | 标签批量管理（重命名/合并） |
| **Folder Note**  | 文件夹作为笔记        |
| **Recent Files** | 最近打开的文件列表      |
| **Waypoint**     | 自动生成文件夹索引      |

## 同步与备份

| 插件                | 功能                    |
| ----------------- | --------------------- |
| **Obsidian Git**  | Git 版本控制，自动提交/推送      |
| **Remotely Save** | S3/WebDAV/OneDrive 同步 |

## 外观美化

| 插件                 | 功能         |
| ------------------ | ---------- |
| **Style Settings** | 精细调整主题样式   |
| **Banners**        | 笔记顶部添加横幅图片 |
| **Iconize**        | 文件夹/文件添加图标 |

## 安装方法

1. 设置 → 第三方插件 → 开启社区插件（旧版叫「关闭安全模式」，现在官方称为受限模式 Restricted mode）
2. 浏览社区插件 → 搜索插件名
3. 安装 → 启用

> 先安装 **Dataview + Templater + QuickAdd** 这三个，能解决 80% 的需求。
