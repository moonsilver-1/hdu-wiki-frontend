##### 3、什么情况下用normal，什么情况下用Max 模式

Max的优势

1. 更大的上下文窗口：

200K Token窗口：完整覆盖Express.js、Tokio运行时等中型框架的核心代码。

1M Token极限：轻松解析Django这类大型框架的核心模块。

实际参考：1M Token约等于3万-5万行代码（按每行80字符估算）。

1. 工具调用自由：

单次任务支持200次工具调用，无需中断即可完成复杂分析。

文件读取能力提升至750行代码，跨文件修改更高效。

 agent 能在更长时间尺度里独立完成更大任务、需要更少的人类指挥；开发者从“写代码的人”转向“建软件工厂的人”——这个工厂由一群 agent 组成，你像带团队一样：给方向、给工具/环境、最后做验收。

比如 OpenClaw 就是一个云端 Agent

在这个时代，已经不需要任何 IDE，不需要关注代码细节，最重要是做验收

第三代的交付物变成了：

日志、录屏、可运行预览的网站/APP/服务等
