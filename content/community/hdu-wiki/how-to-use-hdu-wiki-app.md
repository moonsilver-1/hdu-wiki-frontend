HDU-WIKI 目前有网页端、安卓端 App 和 Windows 桌面端 App 三种使用入口。

三个入口使用的是同一套内容。你可以按照自己的设备和使用习惯选择，不需要重复注册，也不需要在不同端之间切换不同版本的文章。

## 一、先选择适合自己的入口

### 网页端

网页端适合临时查资料、分享文章链接，以及在不同设备上快速打开。

访问地址：

[https://www.hdu-wiki.cn](https://www.hdu-wiki.cn)

### 安卓端 App

安卓端 App 的名称是 **dudu百科**，适合在手机上经常使用 HDU-WIKI 的同学。

手机 App 可以减少每次打开浏览器、输入网址和寻找页面的步骤，也适合在路上、宿舍或校园活动现场随手查询。

### Windows 桌面端 App

Windows 桌面端 App 适合在电脑上长时间阅读文章，或者在写作业、做项目时把 HDU-WIKI 放在独立窗口中使用。

如果浏览器里同时开着教务系统、课程资料、在线文档和其他页面，桌面端可以避免 HDU-WIKI 被大量标签页挤到后面。

## 二、下载安装

### 安卓端 App

安卓端下载地址：

[下载 dudu百科 APK](https://github.com/moonsilver-1/dudu-app/releases/latest)

安装步骤：

1. 打开上面的 GitHub Release 页面。
2. 选择最新版 APK 文件下载。
3. 下载完成后打开安装包。
4. 如果手机提示需要允许安装未知来源应用，请按照系统提示操作。

建议从项目的 GitHub Release 页面下载，不要安装来源不明的转发安装包。

### Windows 桌面端 App

Windows 桌面端下载地址：

[下载 HDU-WIKI Desktop](https://github.com/moonsilver-1/hdu-wiki-desktop/releases/latest)

安装步骤：

1. 打开 GitHub Release 页面。
2. 下载最新版 Windows 安装包或可执行文件。
3. 按照系统提示完成安装或直接运行。
4. 如果 Windows 弹出安全确认提示，请确认文件来源后再继续。

## 三、首页和内容分类

HDU-WIKI 目前主要分为四个内容模块：

### 课程与学术

这里主要放课程笔记、考试经验、学习方法、绩点、升学和学术成长相关内容。

### 校园生活

这里主要放新生入门、选课、校园办事、生活流程、出行和周边信息。

### 技术与项目

这里主要放编程、开发工具、工程实践、AI 使用和项目经验。

### 社团与活动

这里主要放学生组织、社团介绍、志愿活动、校园活动和社区内容。

如果你只知道自己想了解哪一类内容，但还不知道具体文章名称，可以先从分类进入，再按照文章标题选择。

## 四、如何搜索文章

如果你已经知道要查的关键词，直接搜索会更快。

例如：

- 搜索“绩点”，可以查绩点、学分和综测相关内容。
- 搜索“选课”，可以查培养方案、课程号和选课提醒。
- 搜索“社团”，可以查学生组织、青协、科协和兴趣类社团。
- 搜索“竞赛”，可以查比赛介绍、入门建议和项目经验。
- 搜索“投稿”，可以查看 Markdown 投稿和审核流程。

搜索结果会根据文章标题、摘要、标签和正文内容进行匹配。

如果你不知道某个词具体属于哪个分类，也可以先直接搜索。例如不清楚“绩点”是什么意思，搜索“绩点”就能找到相关解释。

## 五、文章阅读

打开文章后，可以按照标题和正文顺序阅读。

长文章建议使用桌面端阅读，屏幕空间更大，也方便同时打开笔记、代码编辑器或其他资料。手机端则更适合阅读短文章，或者利用碎片时间查看一部分内容。

晚上阅读时，可以切换夜间模式，减少亮色页面带来的视觉压力。

夜间模式不会改变文章内容，只会调整页面的显示颜色。

## 六、离线使用

App 端支持离线使用。

在网络不稳定、校园网连接不顺畅，或者暂时没有网络时，已经内置到 App 中的内容仍然可以打开查看。

需要注意的是，离线状态下无法及时获取网站上的最新文章和更新内容。恢复网络后，再打开 App 即可查看最新版本。

## 七、精选阅读和最近更新

首页的精选阅读会放置一些比较适合优先查看的文章，例如新生指南、网站使用说明和重要项目内容。

最近更新用于查看近期新增或修改的文章。如果你想了解 HDU-WIKI 最近补充了什么，可以从这里开始。

## 八、如何投稿

HDU-WIKI 支持在网页端进行投稿。

投稿时通常需要填写：

- 标题
- 作者
- 摘要
- 标签
- 正文

正文支持 Markdown。提交后，文章会进入 GitHub 审核流程，管理员审核通过后才会正式发布到网站。

投稿内容可以是课程经验、校园办事流程、竞赛和科研经历、社团体验、技术文章，也可以是其他对杭电同学有帮助的内容。

投稿入口可以参考：

[最新投稿方式](./latest-submission-guide)

## 九、内容更新和多端同步

网站、安卓端和 Windows 桌面端使用统一的内容来源。

当网站新增文章或更新内容后，其他端会在同步更新后显示对应版本。不同端的主要差别是窗口大小、操作方式和是否方便离线查看。

如果某个端暂时没有显示最新内容，可以先检查网络连接，再重新打开或刷新应用。

## 十、常见问题

### 安卓端和网页版有什么区别？

网页版不需要安装，适合临时访问和分享链接。安卓端安装后可以更快打开，也支持离线查看已经内置的内容。

### Windows 桌面端和浏览器有什么区别？

桌面端可以独立运行，不容易被浏览器标签页遮住，更适合长时间阅读和边查资料边学习。

### App 需要注册账号吗？

目前主要功能可以直接使用，不需要额外注册账号。

### 为什么看不到最新文章？

请先检查网络连接，再重新打开应用或刷新页面。离线状态下只能查看已经内置的内容。

### iOS 和 Mac 端什么时候推出？

iOS 端和 Mac 端已经在开发计划中。由于苹果生态涉及证书、打包、分发和审核等流程，开发和发布会比安卓端、Windows 端慢一些，具体更新时间以后会根据开发进度公布。
