基线：远端 main `aa70bfe4b5054865535f342202658ca718ee33fd`。工作分支：`codex/article-quality`。日期：2026-10-22。

## 修复范围

- 统一文章、作者简介和投稿预览的 Markdown 渲染管线。数学公式转换仅作用于语法树中的公式，不再误改代码中的美元符号；未知代码语言降级为安全文本。
- 修复 Strassen 文章多行公式、AI 编程工具文章美元价格与表格换行、Cursor Rules 文章嵌套代码围栏和未包裹的 Python 示例。
- 兼容历史导入表格的转义换行，补充表格对齐、任务列表及五六级标题样式。原始 HTML 仍禁用。
- 修复课程排序比较器的不一致，Strassen 前后章节恢复为凸包算法和 FFT；目录中的公式不再重复提取两份文字。
- 修复投稿删除中间图片后的引用错位、多图读取期间数量限制竞态、预览错误不显示的问题。客户端和服务端使用同一套语法树校验，覆盖引用式链接和编码协议绕过。
- 修复手机端正文、长行内公式、顶栏和页脚横向溢出。

## 新增功能与质量门禁

- 文章提供复制链接、打印 / 存为 PDF 操作和打印样式。
- 缺少摘要的历史文章从正文首个实质段落生成展示摘要。
- 新增全量 Markdown 渲染检查 `pnpm validate:rendering`，纳入 `pnpm check` 和现有 GitHub Actions 流程。正文规范错误提供行号。
- 增加公式、代码围栏、表格、危险链接、投稿图片、SEO 序列化、课程顺序及目录回归测试。

## SEO 与加载优化

- 文章输出 Article 和 BreadcrumbList JSON-LD，转义脚本结束标签；发布时间保留中国时区。
- 补充首页、分类、作者及独立页面的 canonical，分类和作者描述，以及 Open Graph / Twitter 分享图片。
- 投稿和 Vim 工具页面 noindex；robots 排除 API，站点地图覆盖分类、正文、作者、迎新和观猹页面。
- 搜索弹窗按打开时机加载；开发环境中文件未改变时复用搜索索引，避免每次查询重复读取与索引全部正文。
- 正文图片使用浏览器懒加载和异步解码；公开文章 API、站内图片与迎新资源使用有期限缓存，允许文件替换后更新。
