# 一起，成为更好的自己

## 故事方向

小羊学长和小羊学姐是一起学习、互相支持的好朋友。学长遇到代码问题时，学姐陪他一步步排查；学姐为公开分享紧张时，学长陪她练习。两人最后并肩站上分享会的舞台，台下的同学们为他们鼓掌，喊出“GOAT”。

网站的课程笔记、经验分享是故事里的学习工具。重点是朋友之间双向的关心，以及把获得的帮助继续传给别人。

“你是 GOAT，那我是谁”仅用于独立表情包，不出现在视频里。

## 画面与声音

- 保留已经确定的人类卡通角色：奶油白卷毛，学长鼠尾草绿外套，学姐杏橘开衫与发夹。
- 前半段用独立表情包演出关心、困惑、理解和鼓励；镜头内有对话气泡与字幕。
- 练习分享时，双方都从紧张变得安心。最后一幕始终是两人站在同一个舞台上。
- 学长与学姐使用不同的中文合成声线。观众欢呼由男女声叠加；轻柔伴奏与掌声通过本地脚本合成。
- 按实际配音时长安排镜头，留下反应和换气的停顿；字幕烧录进成片，同时输出 WebVTT。

## 可复现制作

台词、角色、动作与场景定义在 `story.json`。配音脚本只发送自编台词到语音服务，缓存已完成片段；可通过 `STORY_TTS_PROXY` 指定本地已有代理。

```powershell
python scripts/media/generate-story-audio.py
python scripts/media/render-story.py --checks-only
python scripts/media/render-story.py
```

语音缓存齐全时，使用 `python scripts/media/generate-story-audio.py --offline` 重建时间轴与混音，不连接语音服务。离线流程同步解码已有片段，无需创建网络事件循环。最终时间轴为 87.29 秒，最后 6.75 秒保留同台画面和观众的三次 GOAT 欢呼。

需要 Python、Pillow、numpy、imageio-ffmpeg、edge-tts，以及 Windows 微软雅黑字体。图片由内置 ImageGen 生成；`story-art/stage.png` 是最终舞台插画。原来的网站操作演示保留为独立文件。

## 表情包扩充

保留原有 20 个文案，加入 6 个已有独立原图文案，再加入 `stickers/expansion.json` 中的 24 个新文案。两位角色各 50 张，总计 100 张。

新增内容同时包含温柔回应（嗯嗯、怎么啦、没事没事、我在呢、慢慢来）、打气（加油加油、今天也很棒）、校园成长（代码又炸了、运行成功、一起学）和独立抽象梗（GOAT、你是GOAT，那我是谁）。

打包脚本 `package-stickers-v2.py` 在写入网站前检查所有原图齐全、RGBA 真实透明、无重复，以及 ZIP 的 CRC 和逐张哈希。网站提供两份各 50 张的原图包，另存 100 张本地合集，均不降低原图分辨率。
