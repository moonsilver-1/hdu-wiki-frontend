# Welcome assets — final versions

Generated with the built-in image generation tool. Runtime references use only these final assets:

- `xiasha-map-v4.png`: user-provided Xiasha map restyled and corrected for dorm layout, gym location and running points; removed incorrect garden label and restored complete bottom banners.
- `shaoxing-map-v2.png`: supplied Shaoxing aerial map illustrated in the Xiasha map style, preserving nine buildings, waterways, bridges and address. Building 9 is labeled 学生公寓.
- `walk-atlas-v2.png`: complete original-style pixel students with calibrated direction crops. The user chose translation with heading changes; no separate limb animation is rendered.
- `noticeboard.png`: pixel-art campus noticeboard with tiled roof and blank label strip. Runtime previews use the actual campus maps.
- `gift.png`: cream gift box with red ribbon, gold seal and sage leaf.
- `assets.png`: campus buildings.
- `bgm.mp3` and `voices/`: active audio assets.

Superseded generated maps, sprite sheets and the unused articulated character component have been removed from the working tree.
