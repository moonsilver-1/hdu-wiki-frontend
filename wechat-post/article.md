# HDU Wiki 是什么？

一句话：**杭电人自己的校园百科**。

课程怎么学、校园怎么办事、技术怎么入门、社团怎么选……这些你正头疼的问题，学长学姐都帮你写进了 HDU Wiki。站内的口号就一句——**我们期待能让杭电变得越来越好！！！**

> 🔗 线上站点：在浏览器打开 HDU Wiki（开源仓库：github.com/moonsilver-1/hdu-wiki-frontend）
> 🤝 它不是一个只读网站，而是**所有人共建**的百科。

# 一、怎么逛站

## 1. 首页四大焚决，点进去就完事

打开首页，你会看到四张分类卡片，也就是站内的「四大焚决」：

- 📚 **课程与学术** —— 课程笔记、考试经验与学习资源
- 🏫 **校园生活** —— 校园办事、生活攻略与成长指南
- 💻 **技术与项目** —— 编程、硬件、工具与项目实践
- 🤝 **社团与活动** —— 社团介绍、学生组织与校园活动

每张卡片都标了当前文章数，点一下直达对应板块。顶栏的导航也能随时切换这四个分类。

## 2. 搜索：快才是真的快

首页和顶栏都有搜索框。输入关键词（比如「绩点」「竞赛」「git」「实习」）：

- 实时联想，**命中的关键词会高亮**；
- 回车直接跳到最相关的一篇；
- 全程本地搜索，秒出结果，不转圈。

## 3. 白天不懂夜的黑？一键换肤

网站内置 **亮色 / 暗色** 主题。默认会根据时间（晚上 18:00 到早上 6:00 自动切暗色）或系统偏好切换；点右上角的太阳 / 月亮图标也能手动切换。深夜刷 wiki，眼睛更舒服。

## 4. 文章能打：公式 + 代码都好看

技术类文章支持 **KaTeX 数学公式** 和**代码高亮**。推导、原理、示例代码，排版都帮你收拾得整整齐齐，读起来不费劲。

# 二、怎么快速投稿（重点）

网站最香的功能——**网页端免登录投稿**。你不用会 git，不用配环境，填个表单、点一下，文章就以 Pull Request 的形式提交审核了。合并后还会**自动部署上线**。

## 三步搞定

1. 打开 **投稿页**（`/contribute`，首页底部也有「投稿写文章」按钮）。
2. 填表单：
   - **标题**（2–80 字）
   - **作者署名**（必填，光荣留名）
   - **邮箱**（选填，方便编辑联系你）
   - **分类 / 子分类**（下拉选择）
   - **摘要**（一句话简介，会显示在卡片上）
   - **标签**（最多 8 个）
   - **正文**（支持 Markdown，带实时预览）
3. 点「提交」，系统自动开一个 PR。审核通过、合并后，文章就上线了。

> 💡 正文支持 Markdown：标题、列表、加粗、**数学公式**、**代码块**都能用。边写边预览，所见即所得。

## 投稿分类速查

- **课程与学术** → 基础课程
- **校园生活** → 校园生活 / 被迫营业 / 体验生活
- **技术与项目** → 工程实践 / 自动化学习 / 工具使用 / vibecoding / 其他
- **社团与活动** → 社团与活动

> 注：深度学习、算法等精排课程有专属编号体系，暂不开投稿，避免编号被弄乱。

## 投稿小贴士

- ✅ 正文至少 20 字，认真写比凑字数好；
- ✅ 用 Markdown 写，公式、代码块随便上；
- ⚠️ 本站**暂不支持图片**，请用文字、代码或公式表达；
- ⚠️ 正文里别塞 `<script>`、`onclick` 这类可执行代码（会被安全拦截）；
- ✅ 拿不准的内容，审核环节编辑会帮你把关。
